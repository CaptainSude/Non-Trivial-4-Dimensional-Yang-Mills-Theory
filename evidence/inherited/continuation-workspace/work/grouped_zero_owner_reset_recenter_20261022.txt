1. THE n=0 AND FULL BRACKETS HAVE THE SAME FINAL PAIR DOMAIN

Fix one actual final outer canonical geometry at a reset date e, the
retained second-class components Y_i, and their complete raw records r_Y,
omega_Y. The full first-class bracket in LII(1.72) then sums over compatible
removed components X_h and their old histories. The output configuration
and A'_e are outside that sum.

LII365(1.33)--(1.35) gives the determining-array change explicitly:

 Gamma_j,new = Gamma_j,old intersect Z^c, j<e,
 Gamma_e,new = Gamma_e,old union Z^(e),
 V_new|Z^c=V_old|Z^c, with current data on Z.             (1)

Thus a removed X is current-grade in the final array. In the n=0 preimage
of this SAME final record it is already part of the current-grade exterior,
instead of being a region with a separate old history to integrate. This
does not change the final determining array. The retained Y records are
fixed in both representations. The final large-field set is the one in
LII390 after(1.101), namely the old unselected part together with the Y_i;
the removed X_h are not added to it.

Consequently the n=0 crossing term has its own native analytic extension
V_empty(U,J;omega_Y) on this final pair domain. Its old-background pullback
need NOT equal the pullback used in an n>0 summand. Domain inclusion(1.65)
and the bound(1.68) admit its own function on the common output domain;
there is no cross-background equality assertion.

For the retained operations themselves the statement is stronger.
LII378 says the integrations defining T'_e factorize in components of Z.
LII379 immediately after(1.71) states that all expressions of that integral
operation are localized in its component. Thus, with the same final pair
and complete retained record fixed, a T'_e(Y_i) is unchanged when disjoint
compatible removed X components are added to the bracket. This is the
literal component factorization in(1.71)--(1.72), not an equality of old
normalized measures at different exterior arguments.

The crossing function V_empty can therefore be embedded into the full
bracket as the function of the final pair and omega_Y which it already is.
It has no X private arguments. Adding the X integrations changes the
source-zero weight of this test, rather than silently replacing its old
pullback by the n>0 one. All its incident/collar and determining reads are
still those of the n=0 staged function; their actual domain is retained.

2. RECENTER THE COMPLETE RAW GERM BEFORE RETAINED AVERAGING

Work at fixed compatible retained raw history first. Use finite formal
source variables t,u, with t^2=u^2=0. Let W_old be the already stored raw
source germ, with W_old(0)=1. In the n=0 body set

 S_0(t,u) = Delta A'_0 + Delta V_cross,empty
                            + sum_i P_int,Y_i,0,         (2)
 R_0(t,u) = W_old(t,u) exp S_0(t,u).                     (3)

Here every Delta subtracts its ACTUAL source-zero value on the same n=0
pullback; the internal differences and all scalar values are included.
The complete raw germ, not an already averaged value, is meant in(3).
When several native coordinates/operations occur, keep their literal
ordering and joint read until the multiplication has been assembled.

Let dK_act,0 be the actual source-zero output integrand, opened in the
same retained Y coordinates, with its full source-zero first-class bracket.
Define the neutral recentered source expression by

                 dK_neut(t,u)=R_0(t,u) dK_act,0.          (4)

This is a multiplication of the actual integrand by a complete source
ratio. It is NOT division by T'_Y1, by an averaged n=0 mass, or by an old
Q denominator. Equation(4) is formed before retained averaging. All old
normalizers, characteristic functions and actual source-zero weights
remain once.

At source zero(4) is exactly the actual output body. This is the precise
raw version of recentering, where centering only a B coefficient had
left an unresolved representation issue. The expression is an auxiliary
source germ around the actual body, not a claim that the n=0 history alone
is the full physical transition.

3. IT PASSES THE REPRESENTATION-KERNEL TEST AT FIRST AND MIXED ORDER

Write

 W_old=1+t w_p+u w_q+tu w_pq,
 S_0=t s_p+u s_q+tu s_pq.

The raw rows of(3) are exactly

 f_p=w_p+s_p,                  f_q=w_q+s_q,
 f_pq=w_pq+s_pq+s_p s_q+w_p s_q+w_q s_p.                (5)

There is no extra w_p w_q term: the raw w_pq already contains whatever
two-first product belongs to W_old. A separate incoming contact is a
linear s_pq or w_pq contribution; it is not normalized by two first-source
radii.

For the actual completion pair (h,-h), the opposite terms in(2) are
identical functions on the complete staged domain. They cancel BEFORE
exponentiation or averaging. Hence s_p=0 for this null direction, and
the mixed row in(5) vanishes when a null direction occupies one source
slot with its corresponding raw contact rule. More generally two
decompositions of the same ALREADY PULLED-BACK history-resolved complete
raw germ at(2)--(3) produce the same R_0 and therefore the same
expression(4). This is not a theorem that arbitrary old-input
representations passed through different category/localizer maps define
the same independent-pair extension.

This assertion is stronger than equality on physical pairs, but narrower
than equality after summing incompatible histories. The common staged
complex extension, incident/collar read and actual retained coordinates
are part of the equality. One cannot replace only the internal member
of a completion pair by a physically equivalent real RN test while
retaining the external member's independent-J extension.

If a coherent birth occurrence is absent, its complete R_0 is identically
one on that history. Multiplication by dK_act,0 preserves that fact. This
embeds the finite support certificate into the actual unmarked output
weight without claiming that the n=0 and n>0 old minima coincide.

4. THE DIFFERENCE HAS A USED OWNER, BUT THIS IS NOT AN ITERATED NORM

For an already admitted one-reset analytic source construction, let C(v)
be its first-class bracket, and let C_empty(v)=exp V_empty(v). At the
finite-germ level define

 D(v)=log C(v)-V_empty(v).

The formal owner-degree-zero part of D is zero. Where the common retained
factors are exposed, the full source and neutral expressions differ by
the factor

                 exp D(v)-exp D(0).                    (6)

Equivalently their logarithmic source difference is D(v)-D(0).
Thus every source-dependent term in this difference uses an actually
removed operation. If old source rows occur inside the first-class
operations, keep them inside the corresponding admitted marked bracket;
do not factor them out as a common retained multiplier. The same formal
constant-term assertion then applies coefficientwise to that bracket.

The native marked absolute construction can retain the current mass gap
for this used-owner complement, including boundary carriers meeting Y.
That is the already registered rare-emission result; this note does not
supply a new bound for an arbitrary raw crossing insertion.

On the B-only side there is a useful reason that recentering is less
expensive than three triangle inequalities on every old date. The old
dated completion baselines in A' are common. D(0) changes only the new
current-date connected output, whose used-owner part has an exponential
mass reserve. V_empty has the stronger pre-cluster crossing bound(1.68),
whereas the generic new boundary allowance(1.97)--(1.99) is of alpha type.
This suggests a fixed current-date allowance for centering. It does not
by itself certify a family containing all the retained pair-dependent
internal rows in(2), and is not used here as an iterated norm theorem.

6. WHAT THE OPERATION BUDGET WOULD PAY AFTER THIS MATCH

For a genuine normalized all-test map Q on the assembled germ, the raw
rows are Qf_p,Qf_q,Qf_pq, and its logarithmic mixed row is

                  Qf_pq-(Qf_p)(Qf_q).                 (8)

This avoids a repeated physical source disc. A fixed local price per

No whole-volume normalization estimate can be substituted for the local
supported bound, and no loss of a new spatial-exponent margin per stage
has been funded. Temporary LI labels need their actual operation-count
match, not an identification with new physical dates.
