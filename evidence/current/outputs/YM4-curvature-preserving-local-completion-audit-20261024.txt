1. PRECISE BOX AND TREE CONVENTIONS

Use coarse lattice units. Translate the root to 0 and write

  C_R = {x in Z^4: |x_j| <= R for j=1,...,4}.

The input includes every unoriented edge with both endpoints in C_2R
and every plaquette contained there. The cube must fit without torus
identifications. Any native convention including incident edges needs
one additional complete lattice collar; this is a fixed enlargement,
not an inference from incomplete plaquette data.

For each x use the path P(x) that first traverses coordinate 1 from
0 to x_1, then coordinate 2, then 3, then 4. Traversals are signed, so
negative coordinates cause no change of definition. These paths form
one tree: the parent of a nonzero x is obtained by subtracting the
sign of its highest-index nonzero coordinate in that coordinate.
Every parent decreases the l1 distance to 0. Hence there are no cycles,
all vertices reach 0, and the root path is exactly P(x).

Every prefix of P(x) lies in each centered cube containing x. Thus
the restrictions of this SINGLE infinite coordinate tree to nested
centered cubes agree. One must keep the same root and coordinate order;
independently chosen trees on different cubes need not agree.

Let G(x) be the ordered input parallel transport along P(x), and put

  V^can(x,y) = G(x) V(x,y) G(y)^(-1).

All tree edges are identity. The proof does not suppose that the input
links, input tree transport, or a chosen initial gauge are small.

2. THE LINEAR STRIP BOUND, INCLUDING SIGNED COORDINATES

Fix a positive edge e=(x,x+e_j) contained in C_2R. The paths P(x)e and
P(x+e_j) have the same part in coordinates less than j. Their remaining
discrepancy is precisely moving ONE e_j step past the signed coordinate
segments k=j+1,...,4. One plaquette swap moves it past one such step.
It follows that the based loop P(x)eP(x+e_j)^(-1) can be filled with

  N(e) <= sum_{k>j} |x_k| <= 2(4-j)R <= 6R

plaquettes. These are width-one strips, not the full rectangles between
arbitrary root paths. For j=4 the number is zero, consistently with the
tree structure.

This argument also covers x_j<0 and the edge from -1 to 0. After the
higher-coordinate segments have been crossed, the final positive j
step cancels the last negative j step in P(x), giving P(x+e_j).
Negative higher coordinates merely reverse the corresponding strip.
All strip coordinates lie between 0 and the two edge endpoints, hence
all plaquettes used are contained in the filled input cube. Reverse
edges follow by inversion. This verifies boundary compatibility of the
area estimate rather than presuming an infinite-field extension.

Each plaquette swap expresses the loop transport as a product of
unitary conjugates of input plaquette transports or their inverses.
If every input plaquette satisfies ||V(dp)-1|| <= delta, telescoping
the unitary product gives

  ||V^can(e)-1|| <= N(e) delta <= 6R delta.                 (1)

For a fixed sufficiently small matrix-log neighborhood, (1) implies

  V^can(e)=exp(i A_e),   ||A_e|| <= C R delta,
  A_{-e}=-A_e.                                           (2)

The hypothesis R^2 delta <= c, R>=2, with c fixed sufficiently small,
is more than enough to place every edge in this log neighborhood.
The constants depend on the fixed group/norm and dimension, not R.

3. CURL AND CUTOFF ESTIMATE

Let a plaquette have oriented edge logarithms A_1,...,A_4, with signs
included by reversing the appropriate edges. For four small matrices,
the elementary BCH estimate gives

  ||log(exp(iA_1)...exp(iA_4))-i sum_l A_l||
      <= C (max_l ||A_l||)^2.

The first logarithm is bounded by C delta, because the actual
canonical plaquette is a unitary conjugate of an input plaquette.
Consequently the additive curl, in the single canonical matrix frame,
obeys

  ||dA(p)|| <= C(delta+R^2 delta^2).                       (3)

Choose a fixed smooth one-variable function equal to 1 on [-1,1]
and 0 off (-3/2,3/2). The product of its four coordinate factors,
evaluated at the midpoint of each edge divided by R, defines an
unoriented scalar chi_e. Then chi=1 on edges in C_R, chi=0 in a full
outer collar of C_2R, and any two edges of one plaquette satisfy

  |chi_e-chi_f| <= C/R.

Set B_e=chi_e A_e on the input edges and B_e=0 elsewhere, and define
Vhat_e=exp(i B_e). For any plaquette wholly within C_2R, choose one
of its edge cutoffs chi_* and write exactly

  dB(p)=chi_* dA(p)+sum_{e in dp} sign(e)(chi_e-chi_*) A_e.

The second term is at most C R^(-1) R delta = C delta. Applying
the same FOUR-edge BCH bound to B gives

  ||Vhat(dp)-1|| <= C(delta+R^2 delta^2) <= C' delta.       (4)

For a plaquette crossing the outer boundary all of its possible
nonzero B edges lie in the zero collar and are in fact zero. Thus
(4) also holds across the extension seam and outside the input cube.
The definition is exactly the canonical input on all inner C_R
edges, and exactly identity outside the cutoff support. There is no
uncontrolled seam plaquette. Small fixed boxes can be treated by one
fixed enlargement; it is enough to state the theorem for R>=2.

The condition R^2 delta<=c is substantive: the elementary proof pays
the noncommutative quadratic BCH term. It is not justified to remove
this condition by calling the cutoff a gauge transformation.

4. ROOT GAUGE EQUIVARIANCE AND WHAT IS PRESERVED

For a real input gauge u defined on the filled box,

  G_{V^u}(x)=u(0)G_V(x)u(x)^(-1),
  (V^u)^can(e)=u(0)V^can(e)u(0)^(-1).

The small principal log and the fixed scalar cutoff commute with
constant conjugation. Hence the completed field obeys exactly

  Vhat(V^u)=u(0)Vhat(V)u(0)^(-1)                           (5)

on the whole completed lattice. This is root-frame covariance.
Gauge-invariant observables supported on complete inner reads are
unchanged by passage from V to V^can. They are not asserted unchanged
by replacing the old global field or old minimum with Vhat outside
the protected read. For two radii, the canonical fields agree on
their common input, but the cutoff completions need not agree in
their transition annuli.

The construction is pointwise on a held datum. It does not use the
field-dependent map V -> V^can as a measure-preserving change of
outer integration variables. No outer Haar Jacobian or orbit-volume
cancellation is inferred from (5).

6. LIMITS OF THIS AUDIT

box and a nonwrapping coordinate realization. It does not repair a
missing mixed determining seam or supply control on torus holonomies
when the cube wraps. It is for real compact-group input; arbitrary
complex input has no unitary product estimate (1) without additional
bounds. It proves a new homogeneous completion and minimum, not that
the physical original law lies in this event with high probability,
not equality to the old random/noisy source image, and not an
all-history or continuum theorem.
