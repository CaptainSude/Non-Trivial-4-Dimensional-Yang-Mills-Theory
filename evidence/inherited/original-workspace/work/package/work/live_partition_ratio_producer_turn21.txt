2. WHAT SUMMING THE REFERENCE ACTUALLY CANCELS

Fix a real admitted geometry, its gauge slice, and every pre-redraw label
h. Let x be exactly the current links changed by this redraw, xi any old
retained integration variables, and e every untouched link/boundary datum
read by the reference or the spectator. Write the positive incoming
measure as tau_h(de,dx,dxi), including ALL its Wilson/E/R/boundary terms,
cutoffs, masks, inverse normalizers and vacuum convention. Let

  m_h(de)=integral tau_h(de,dx,dxi),
  s_(h,e)(dy)=r_(h,e)(dy)/I_(h,e),  I_(h,e)=integral r_(h,e).

The literal normalized-redraw joint law, wherever this is the branch rule,
is tau_h(de,dx,dxi)s_(h,e)(dy). Thus for every exterior-measurable F,

  integral F(e) tau_h(de,dx,dxi)s_(h,e)(dy)
                      = integral F(e)m_h(de).                    (2.1)

No positive lower bound for m_h is used. Singular axial slices are honest
reference measures in this identity. A compatible anchored gauge change
does not change (2.1) for gauge-invariant F. An additional output gate
b(e,y) cannot be moved into tau_h before redraw. Summing its two exact
class labels b and 1-b recovers (2.1); retaining one class leaves

                   integral F(e)m_h(de)s_(h,e)b.                  (2.2)

For disjoint refills with disjoint complete exterior reads, products of
s_(h,e) have the same property. No independence of the incoming x is
required. If a reference reads another changed variable, use the actual
sequential kernel and its larger unchanged exterior instead. A product
of mutually new-variable conditionals cannot be declared normalized.

Consequently every exterior event E is invariant: K_h 1_E=1_E. This is
the concrete obstruction to obtaining a new penalty by summing redraws
when the surviving component is forced by a retained-collar test. It is
an exact statement about a specified operation, not a claim that annealed
component rarity is false for the actual Wilson law.

Even inside Lambda, baseline holonomy/current may use the available
native threshold without a strict margin. A tail relative to the local

The source's adequate weak regularity is not automatically the smaller
baseline condition in (5.2).

This is a counterexample to the proposed inference from REFILL data;
