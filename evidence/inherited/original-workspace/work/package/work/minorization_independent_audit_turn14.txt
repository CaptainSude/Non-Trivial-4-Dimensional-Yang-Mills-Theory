1. EXACT MEASURE LEMMA AND ALL NORMALIZATIONS

On a fixed stopped graph let lambda be normalized product Haar, V its
stopped cell count, and e its independent positive link count. Suppose

  Mhat_eta >= exp[-a(g)V] chi_eta exp[-A_eta/g^2] lambda,
  0 < Mhat_eta(X) <= exp[b(g)V].                         (1.1)

These must be inequalities for the SAME positive finite measure, in the
SAME vacuum convention and with the SAME stopped graph. No global density
upper bound is required. A singular additional positive sector is allowed.
If the actual measure is C_eta Mhat_eta, its scalar C_eta cancels EXACTLY
in normalization; separately normalizing the selected regular contribution
would not be the same argument.

Assume a fixed eta-independent product log ball B_delta obeys

  chi_eta=1 on B_delta,  A_eta <= C V delta^2 there.       (1.2)

With h(delta) the one-link Haar mass, set

  nu_delta = h(delta)^(-e) 1_(B_delta) lambda.

For every positive measurable test f, (1.1)--(1.2) give

  E_mueta f >= exp[-(a+b+C delta^2/g^2)V]
                  h(delta)^e E_nudelta f.               (1.3)

The Haar power is e, not the number of observed links and not the number
of fine links. On a periodic four-dimensional stopped cubical lattice
e=4V in the standard positive-orientation convention. More general fixed
boundary conventions may change this to e<=C_d V. Since
c delta^(dim G)<=h(delta)<=C delta^(dim G), choosing delta=c0 g yields

  log alpha >= -[a(g)+b(g)+C1+C2 |log g|]V.              (1.4)

This retains the entire total-volume cost. No local thermodynamic bound
or polynomial dependence of a,b on g follows. A fixed weak band also
requires the stated uniform bound of a,b on that band; finiteness at each
g separately would not imply it.

The same numerator lower bound gives a strictly positive denominator
floor. Thus no circular use of an already normalized history occurs.

2. THE HOMOGENEOUS ACTION ESTIMATE IS CORRECT

The established homogeneous physical minimum module supplies, on its
fixed common small coarse-field ball,

  ||1-U_eta(exp B)(partial p)|| <= C eta^2 ||B||_infty.

For a unitary matrix W the exact identity

  dim(rho)-Re Tr rho(W) = (1/2)||I-rho(W)||_HS^2

turns this into a plaquette action O(eta^4 ||B||^2). There are at most
C_d eta^(-4)V fine plaquettes. In dimension four their product is
C V||B||^2, uniformly in eta. Hence the global action bound in (1.2)
follows from that module, with its already stated source/gauge hypotheses.
There is no omitted eta^(-4) factor and no replacement of fine entropy by
coarse entropy: this calculation bounds the action of ONE minimizing
configuration, not a partition integral.

An equivalent envelope calculation uses the bounded homogeneous coarse
precision q and V(B)=<B,qB>/2+O(V||B||^3). This also yields the same action
bound, but says nothing further about the cutoff's other local minima.

3. WHAT IS STILL REQUIRED FOR THE ACTUAL CUTOFF

Primary B119 (2.16)--(2.17), pp256--257, defines the cutoff through a
localized minimal determining tower based on an enlarged cube and tests
an inner enlargement. The tower datum is induced by the copied field
Q^k V. This is not literally the full-torus homogeneous minimum map.
The two exact checks needed are:

 (D) That complete tower datum, including its graded boundary rows, is
     admitted by the native minimum theorem with parameter <=C||B||,
     for V=exp B, with C independent of k and torus size.
 (P) Every tested fine plaquette belongs to the protected top-scale
     domain where that theorem gives C||B|| eta^2 curvature.

Then choosing Cc0g below the current threshold proves chi_eta=1 on the
common box. This only concerns the current homogeneous cutoff; it does
not require extending arbitrary old operators or free-current contours.

Raw I155039--155083 gives the intended CMP102 Theorem1(7)--(8) argument.
It imports the datum regularity and uses the two-layer inset property to
place the tested inner cube in the top domain. I independently recovered
the primary cutoff construction and inset description, but not the full
CMP102 mixed-datum hypothesis for this copied field. The archived global
homogeneous C1 bound does not supply (D) merely by declaring an
identity-compatible completion. Thus (D), and the precise source
identification in (P), remain explicit attachment checks in this pass.

One possible alternate verification would use the identity-base analytic
minimum theorem: prove a refinement-uniform bound for all tower datum
logarithms produced by Q^k exp B, then apply its weighted top-domain
curvature estimate. That also requires the actual input dictionary; this
audit does not assert an unverified M^j Q^k identity.

For the weaker fixed-volume conclusion it would suffice to find ANY
delta(T,g)>0 and finite C(T,g), uniform in eta, for which (1.2) holds.
The stronger delta=c0g and volume-linear action constant are useful but
not logically necessary for a positive fixed-T minorization. An
eta-dependent shrinking box would not suffice.

4. GRAM AND LIMIT CONSEQUENCES

The uncentered matrix inequality follows by testing (1.3) on
|sum c_a F_a|^2. The centered statement is also correct:

  Var_mu(F)=inf_z E_mu|F-z|^2
           >=alpha inf_z E_nu|F-z|^2.

Hence independence modulo constants on the box gives a centered Gram
floor at fixed T,g. The functions must be fixed coarse functions with
their box independence separately proved. This does not transfer to
renormalized microscopic observables without the actual insertion map.
For bounded continuous functions, compactness of the fixed coarse group
space and weak convergence preserve both measure order and their Grams.
No compatibility between different stopping resolutions is provided.

5. SOURCE AND MARKOV SCOPE

Primary B122II (0.1), pp355--356, is the source location of the stability
sandwich. The exact typography/volume subscripts were not recovered as
pixels here, so the note correctly records the operational measure and
integrated versions as inputs. The scale is the stopped unit scale;

This matters for microscopic observable transport, but is not needed
inside the abstract proof (1.3), which starts with a specified positive
