ROOT'S INDEPENDENT AUDIT OF THE TWO-PROJECTION OBSTRUCTION -- PASS

The five-staple realizations of A=I and B(t)=(-1+t)I use unit quaternions
and distinct actual exterior links. The second set can move without
altering the first star. Each moved link has speed 1/sqrt(3) at t=0.
The first projection is H_beta(v)=6-|I+v|m(beta|I+v|). The actual second
projection at the old coordinate u=I has density proportional to
exp(beta t v_0), so its derivative at zero is exactly
beta Cov_Haar(H_beta,v_0).

Root checked the Haar coordinate density, the uniform bound
0<=H_beta-(6-|I+v|)<=3/(2beta), and

 E_Haar[v_0 sqrt(2+2v_0)]=64/(105pi),
 E_Haar|v_0|=4/(3pi).

Consequently T_beta'(0)=-64beta/(105pi)+E_beta with
|E_beta|<=2/pi. Completion to the original eleven-plaquette source
adds (1-t)m(beta t), whose derivative is beta/4. Exterior-only
plaquettes contribute at most 4sqrt(3), independently of beta.
The resulting full locally constant source derivative is

 beta[1/4-64/(105pi)]+R_beta,
 |R_beta|<=2/pi+4sqrt(3).

This is a real pointwise obstruction to an unrestricted uniform
response class for repeated original-law projections. It is not a
counterexample to a full Wilson expectation or covariance bound.
The example does not give the Wilson probability of these exteriors.
In particular it is consistent with the separately proved near-flat
joint-integration theorem.

The monotonicity and total-variation bound of two hold for the
single-star function T_beta along this path. They must not be asserted
unchanged for the completed source, and a path measure is not the
full exterior marginal. Repeated projections can reintroduce a
previously updated coordinate, so they are not a nested conditional
expectation or a decimation of both links.
