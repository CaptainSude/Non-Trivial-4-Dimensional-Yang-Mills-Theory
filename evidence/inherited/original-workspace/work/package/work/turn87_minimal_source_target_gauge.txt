TURN87 -- THE MINIMAL SPECIFIC SOURCE TARGET, AND WHAT IT WOULD PROVE
20 October2026. gauge47. Scoped review; no new YM4 existence claim.

DECISION

The current uniform modulus for arbitrary continued bounded tests is a
SUFFICIENT interface for one proposed native comparison. It is not a
logically necessary condition for existence or even for a nonzero original
reflected channel. After the exact first-switch sibling/product identities,
there is no approximation defect in that coordinate change itself.

For the already defined bounded spatially flowed magnetic scalar, the
smallest concrete missing estimate is ONE normalized, connected reflected
two-source coefficient at fixed physical smearing and calibration. The
bounded scalar field already has elementary distributional tightness.
This identifies a narrower observable target; it does NOT replace tightness,
locality, O(4) covariance or identification of a full Yang--Mills algebra.

The probe, Gaussian point margin and two-expectation criterion are old
results (TURN61/63). The present contribution is to separate their actual
source norm from the stronger arbitrary-test native modulus, and to ensure
that the lower bound is stated on a distributional SMEAR rather than a
point value that weak distributional convergence need not preserve.

1. KEEP THE TWO SOURCE NORMALIZATIONS DISTINCT

The literal action source in turn83_native_action_history.txt Section1 is
  F_a(f)=c0 sum_p f_p h_p(U),   h_p=1-Tr U_p/2,
with c0=beta0 for canonical action and c0=1 for coupling-free action.
The same original c0 multiplies all later first jets and c0^2 all mixed
jets; it is not replaced by a later running beta. Nested interpolation
does not change that fact. Scalar/vacuum derivatives and repeated-mark
contacts belong to the normalized source generating function.

In the usual SU2 convention beta0=4/g0^2 and
U_p=exp(i g0 a^2 F_p.sigma/2), the leading smooth-field term is
  beta0 h_p = a^4 |F_p|^2/2 + higher orders.
Thus a fixed spacetime action profile has f_p=O(1), not a^4 f_p.
Its crude absolute source census W_f=sum|f_p| is O(a^-4).
TURN81 Section3's O(W_f W_h) real covariance budget consequently does
not give a uniform physically calibrated action-distribution bound.
Replacing the source by a^4 F_a solves that crude bound only by changing
the smooth-field observable to one tending to0. Centering removes its
mean, not this covariance/contact issue.

The different bounded probe below does use a^4 in its scalar spacetime
average, because its pointwise scalar has size at most1. This is not an
action-source renormalization or an interchangeable source convention.

2. ONE EXPLICIT ORIGINAL PROBE FAMILY

Use exactly spatial_flow_probe_turn63.txt Section1. For every original
finite Wilson lattice, evolve spatial links separately at each time by
spatial Wilson gradient flow at fixed PHYSICAL flow time s>0. Write its
12-plaquette as P_s=p0 I+i p.sigma and fix h>0,g_*>0. Define
  b_a(t,x)=exp[-h |2p(P_s(t,x))/(g_* a^2)|^2].             (2.1)

This is a deterministic function of ORIGINAL links, gauge invariant and
in[0,1]. It reads only its own original time slice. Flow on a periodic
spatial torus is used here; it need not be spatially local within that
slice. The reflected function uses the reflected original field. The
finite flow needs no continuum flow theorem for this definition.

Choose ONE f_*>=0, smooth, integral1, compactly supported in a box a
fixed positive time d away from both reflection planes. Let b_a be its
piecewise constant spacetime interpolation, with reflection-compatible
cells, and set
  O_a(f)=integral f(t,x)b_a(t,x) dt dx.                    (2.2)
Equivalently use exact cell-integral weights on the lattice. Then
0<=O_a(f_*)<=1. This avoids arbitrary quadrature normalization errors.
Take the same physical s,h,g_*,f_* along ONE specified sequence of
Wilson regulators, couplings and physical volumes.

The choice g_* is an observable parameter, not a proved renormalized
coupling. TURN63 Section7A explicitly shows that a bare Gaussian with
g_a/g_*->0 makes this particular radial field tend to1 and its connected
reflection covariance vanish. The original-law matching at the fixed
physical smoothing scale is still required. Changing g_* with the cutoff
would define a different family whose calibration must be stated again.

3. THE EXACT MINIMAL TWO-JET FUNCTIONAL

Put O_+=O_a(f_*), O_-=O_a(theta f_*), and use the ORIGINAL normalization:
  L_a(u,v)=log E_mu_a exp(u O_+ + v O_-),
  C_a(f_*)=partial_u partial_v L_a(0,0)
          =E_mu_a O_- O_+ - E_mu_a O_- E_mu_a O_+.        (3.1)

The minimal missing quantitative target for this scalar channel is
  liminf_(same regulator sequence) C_a(f_*) > 0.         (3.2)
It is one mixed functional, not an operator norm over every bounded
remaining test, every exterior, or every original source. For a comparison
argument it suffices to bound the absolute difference of this mixed
functional from a specifically calibrated positive reference by less than
that reference value. This rank-one error functional is weaker than bounds
on all raw one/two rows separately. If raw rows are used to compute it,
the common 00 denominator and 10,01,11 rows are all retained.

There is no scalar-source analyticity obstacle here: the normalized
M_a(u,v)=E exp(uO_++vO_-) is entire with
|M_a(u,v)|<=exp(|u|+|v|) at EVERY cutoff. Moreover, for
|u|+|v|<log2, |E exp(uO_++vO_-)-1|<=exp(|u|+|v|)-1<1,
uniformly in the cutoff. Thus the normalized logarithm and all fixed
source jets exist on a common smaller disc. This concerns source variables
only; it supplies no native-background holomorphy or complex inverse map.
It is the bounded-source fact already isolated in TURN81/82, applied to
the declared original probe, not a new all-history theorem.

On the exact site-reflection disintegration, let B be BOTH original fixed
slice fields, pi_a their original marginal, and Q_B the actual positive
half conditional law. Then turn75_full_law_tail.txt Section1 gives
  C_a(f_*)=|| Q_B O_a(f_*) - E_mu_a O_a(f_*) ||_L2(pi_a)^2. (3.3)
Thus the requested lower bound is information retained by ONE particular
original positive-time observable in the boundary channel. Neither a
nondegenerate boundary marginal nor ordinary Var(O_a)>0 is enough.
No selected reference conditional may replace Q_B.

4. WHAT TIGHTNESS IS AUTOMATIC FOR THIS BOUNDED SCALAR

This observation concerns only the field b_a of(2.1). On a fixed compact
box K its law is supported in the weak-* compact unit ball of L-infinity(K),
which is metrizable because L1(K) is separable. Across an increasing
countable exhaustion, restrict compatible fields to each box and take
the closed consistent subset of the product of these compact balls.
This is a compact metrizable state space for locally bounded fields,
identified up to almost-everywhere equality. Consequently their laws
have subsequential limits without a further moment estimate.

Alternatively uniform L2(K) bounds give compactness in H^(-r) on a
larger periodic box for every r>0: Fourier tails in that norm are bounded
by(1+N^2)^(-r)||b_a||_2^2, while finitely many low modes form a bounded
finite-dimensional set. Local cutoffs give the same local conclusion.

For any finite collection of smooth compact tests, b->b(f_i) and their
products are continuous and uniformly bounded on the compact field set:
  |E prod_i O_a(f_i)| <= prod_i ||f_i||_1.                (4.1)
Therefore all such moments pass along the SAME extracted law. Reflection
positivity of cylinder polynomials in strictly positive-time smears passes
as well: these are original positive-half functions at each cutoff, and
their reflected polynomial products are continuous bounded functions of
the limiting scalar distribution. Cell approximations cost at most the
L1 error of the test. Centered reflection covariance also passes, so(3.2)
would yield a nonzero centered OS vector in that limiting scalar system.

Along an infinite-volume, translation-invariant regulator sequence, the
same bound |b(tau_y f)-b(f)|<=||tau_y f-f||_1 passes translations from
lattice approximants to continuous test translates. This is a test-space
continuity argument, not a derivative bound on individual flowed fields.
At fixed physical torus it gives only the corresponding torus statement.

None of this constructs the full YM field algebra. Spatial flow singles
out a time direction and has spatially nonlocal reads. O(4) covariance,
locality/identification with Yang--Mills observables, removal or consistent
variation of s, and the joint physical coupling/volume limit are separate.
One positive centered OS norm could also survive in a nonergodic mixture
as a zero-energy invariant variable. Vacuum uniqueness, positive-energy
content and the mass-gap claim need additional component/clustering or
spectral information. The component-product hypotheses reviewed in
turn83_positive_probe_volume_review_root.txt are not supplied by(3.2).

5. THE REFERENCE SIGNAL: OLD RESULT, NOW MATCHED TO A SPACETIME SMEAR

TURN63 already proves v_s=1/(48pi^2 s^2), the magnetic Maxwell covariance,
and the radial Gaussian reflected margin. To avoid using a point value
in Section4, take the existing reference at separated points:
  c_s(tau,r)=integral dk/(2pi)^3 exp(ik.r-2s|k|^2-tau|k|)
                          (k1^2+k2^2)/(2|k|).
For three independent colors, choose h=1/(2v_s). Its two-point connected
radial covariance is
  D_s(tau,r)=(4-[c_s(tau,r)/v_s]^2)^(-3/2)-1/8
             >=3[c_s(tau,r)/v_s]^2/64.                  (5.1)

Here c is real and may have either sign; only its square occurs. The
old point result gives r_*=c_s(2T,0)/v_s>0 for fixed T>0.
The same Fourier integral gives the elementary extension
  |c_s(tau,r)-c_s(tau',r')|
       <=v_s mu_s(|tau-tau'|+|r-r'|),
  mu_s=3sqrt(pi)/(4sqrt(2s)),                            (5.2)
for nonnegative times. The factor mu_s is the mean |k| in the normalized
nonnegative Fourier weight, already computed in TURN63(3.3).

Choose f_* supported in[T-eta,T+eta] times a spatial ball of radius ell,
with eta<T/2 and eta+ell<=r_*/(4mu_s). For two points in this support,
their reflected time difference is within2eta of2T and spatial separation

  C_G(f_*)=double integral f_*(x)f_*(y)D_s(t_x+t_y,x-y)
                          >=3r_*^2/256>0.              (5.3)

This small-smear consequence simply makes the old Gaussian calibration
compatible with distributional compactness; it is not a new interacting
comparison. A direct estimate
  |C_a(f_*)-C_G(f_*)| <= C_G(f_*)/2                     (5.4)
on the same physical sequence would suffice. The stronger old criterion
controls mean and reflected product separately to error epsilon, giving

can instead be proved directly. Whole-space formulas above require a
justified large-volume comparison when used at finite spatial volume.

6. EXACT STATUS OF THE AVAILABLE ESTIMATES

(a) TURN63 supplies the definition, free lattice limit and signal, but
not the nonlinear original-law comparison or g_* matching. The rough-data
spatial-flow admission and its nonlinear derivatives remain unresolved.

(b) TURN81 real positive-augmentation/Jensen/martingale bounds apply to
this bounded O without W_f divergence: every conditional first/mixed row
lies in[0,1], and sum_j ||d_j O||_2^2<=Var(O)<=1/4. The mixed innovation

(c) TURN82 HS smoothing preserves buffered original OS vectors, including
this O whenever its complete halo remains on the positive half. It cannot
increase a zero OS norm. The operator is not multiplicative: the correct
source package is P^n exp(uO_++vO_-), whose mixed jet is P^n(O_+O_-).
The proved derivative bounds do not establish(3.2). TURN82 physical time
translation continuity is already available for bounded buffered states;
it gives an upper modulus, not this missing norm floor.

(d) TURN83's exact finite-source jets concern original plaquette energies
beta0 h_p and their HS integrated coefficients. Their initial weak-chart
curvature grading and conditional source support are genuine. But for
distant source stars its exact law of total covariance is
  Cov_mu(E_p,E_q)=Cov_mu(P E_p,P E_q).
All the separated covariance remains in the outer ORIGINAL law. The
local estimates neither bound it below nor admit the growing nonlinear
read of spatial flow automatically. The homogeneous native primitive's
double profile gain likewise does not include arbitrary earlier source
jets/raw histories, and retains c0^2.

(e) TURN66/67 prove that physical-size thin unrenormalized Wilson loops
and specified bounded processing of them can have vanishing reflected
channels despite nonzero ordinary variance. Thus they are not a substitute
for this flowed probe. TURN69 attaches fixed-spatial temporal source jets
and identifies separated spectral windows, including electric/current
and vacuum/contact terms; it does not give their spatial-cutoff floor.

7. CONSEQUENCE FOR THE CURRENT FIRST-SWITCH PROGRAM

TURN87's actual common-parent sibling identity retains the old cut and
the full original marginal. The first switched cutoff product is exact,
and its own new-chi crossing is zero at the stated support/plateau scope.
Thus no arbitrary-test modulus is required to justify that change of
coordinates. A quantitative modulus becomes relevant only if one CHOOSES
to compare unequal future reads/weights or a reference construction.

For the minimal target(3.2), the necessary source test class can be just
the four completed original rows1,O_+,O_-,O_+O_-, assembled into(3.1),
or directly that one connected coefficient. A bound against every bounded
unfinished test and every fixed exterior is stronger. Exact later positive
integration is allowed to create cancellations before the estimate; it
need not be majorized by a total-variation operator norm at every step.

This does not prove the narrow bound. Current local normalizer control,
first-switch endpoint displacement and fixed-slot modulus do not control
the complete original boundary channel(3.3). Conditional/coarse means
still contain the signal. The flow reads a growing number of links, so
replacing its source by a finite-degree action jet is not legitimate.

For a LOCAL canonical action algebra instead, the corresponding weaker
than-TV target is a physically normalized smeared connected-source bound
on chosen separated profiles, together with an actual contact/field
renormalization and distributional moment controls. The two-time criterion
in temporal_filter_physical_probe_turn67.txt Section6 and the exact window
identity of TURN69 already state this alternative. Its unbounded sources
do not enjoy Section4's automatic tightness, and no such full-law estimate
has been proved. It is presently closer to the native analytic source
class, but is not already calibrated by a constant-action estimate.

RECOMMENDED PRIORITY

Treat the all-history arbitrary-test modulus as one proposed sufficient
technical route, not as the definition of the existence problem. For the
weakest concrete nonzero-state milestone, freeze(2.1)--(2.2) and seek(3.2)
or(5.4) directly, with the same original law, physical sequence and source
calibration. For full YM4 retain the separate local-algebra, symmetry,
renormalization, component and positive-energy obligations. No existing
proved input currently supplies the decisive lower bound for this probe.
