1. THE TWO SPATIAL NORMS ARE USED IN THE RIGHT ORDER

N_j is the neutral birth class with exponent kappa_hi and fixed flat
radius b. B_j is the current value class with exponent kappa_lo, where
kappa_hi>kappa_lo. The direct Holder static theorem gives

       A(n,j):N_j -> B_n,
       ||A(n,j)|| <= A0 r^(n-j),  r=L^-alpha,
       A0=C b^-5.

Its support reserve is spent once in propagating each frozen birth.
It is NOT spent again after every date. In particular the statement
does not infer that an arbitrary low-weight current representative is
a fresh high-weight neutral birth.

The quantum hypothesis is correspondingly the stronger assertion

       K_j=N_E U_j:B_j -> N_(j+1),
       ||K_j|| <= kappa g_j^2.

It includes adjacent-grade restoration of the high exponent by the
actual complete quantum compiler/reblocking. A low-to-low quantum
bound alone would not suffice. The updated draft states this explicitly.

For clarity about a possible parameter allocation, if the actual
column leaves a reblocking amplification a_L>1 and consumes a fixed
input exponent ell_Q and output reserve ell_out, a sufficient pair is

 kappa_hi >= kappa_lo+ell_S,
 kappa_hi+ell_out <= a_L(kappa_lo-ell_Q),

where ell_S is the static support reserve. These inequalities can be
satisfied with once-fixed parameters when
(a_L-1)kappa_lo>a_L ell_Q+ell_S+ell_out. This is an explicit compatible
budget, not a replacement for checking those constants in the actual
quantum column. Its polynomial Gaussian moments and projected-reference
costs must also fit the stated reserve. Original hierarchy choices,
cuts and common domains remain the actual ones.

The patched draft identifies two representations only if they agree
as holomorphic functions for EVERY admitted independent pair (U,J)
and EVERY retained profile f, with the scalar/reference ledger intact.
The norm is the infimum over complete representations of that same
function. Equality only at physical minima would not justify this.

The direct static theorem's intrinsic correction is

                  Q_H(U)=T_H(K_old(U;x)),
                  sum_H Q_H(U)=0,

with the SAME root curvature in every term. This is an exact identity
for all admitted independent pairs and all f. It therefore preserves
the quotient, including its offgraph current germ.

Static substitution preserves the identity whenever its complete image
is admitted. The quantum map preserves it when the SAME coherent
source map Psi_s and the SAME full normalized old kernel are used in
all copies. Absolute complete-carrier bounds justify exchanging the
sum and finite integration. Scalar/reference extraction is linear and

An arbitrary coefficient-dependent analytic extension could destroy

compiler must sum back to the same global source kernel; unrelated
localized maps cannot be substituted termwise without that identity.

3. THE DIRECT RESOLVENT AND MACROBLOCK CLAIM

For P generated by S_j+K_j, variation of constants gives exactly

 E_n=A(n,i)E_i+
           sum_(j=i)^(n-1) A(n,j+1)K_j E_j.

The input to every A(n,j+1) in the sum is a genuine fresh neutral birth.
Thus no claim about the instantaneous beta of an aged E_j is needed.
With g_*^2 bounding the interval and

                  nu=r+A0 kappa g_*^2,

the geometric convolution is bounded by

       ||P(n,i)F||_(B_n)<=A0 nu^(n-i)||F||_(N_i).

The factor A0 appears only in the indicated majorant; it is not
multiplied once per static date. The draft's scalar recurrence and
its explicit resolvent give the displayed bound. Choosing a fixed
m with A0 r^m<=1/4 and then a weak floor with A0 nu^m<=1/2 is valid.

This is initially a birth-to-current bound, not yet a repeatable
operator on a single current norm. The draft says so before using
the invariant construction in Section4. There is no hidden early
macroblock restart.

4. FINITE-HORIZON STATIC-ORBIT SPACE

For the linear span of dated neutral births at date j, define

 ||F||_*j=sup_(j<=n<=H)
               theta^(-(n-j))||A(n,j)F||_(B_n),  r<theta<1.

Each aged birth has finite norm by the static estimate. The n=j term
controls the current B_j norm. On this span the exact semigroup gives

 ||S_j F||_*(j+1)<=theta||F||_*j,
 ||K_j F||_*(j+1)<=A0 kappa g_j^2||F||_*j.

The second line uses the RESTORED high birth range of K_j. These
bounds extend to the completion and give a contraction for
q=theta+A0 kappa g_*^2<1. This is an actual invariant space of the
same coherent functions; no assertion beta_(j+1) S_j=beta_j is used.

The supremum stops at the actual finite horizon H. Every map and
domain appearing in it is part of that finite construction. All
constants are independent of H, so no fictitious infinite future of
a finite regulator is introduced. This uniformity is exactly what
the lemma claims; existence of an infinite-volume or full-history
limit does not follow merely from writing this norm.

6. COUNTERTERM AND VACUUM DRIVERS ARE NOT CONTROLLED BY VALUE STABILITY

The draft retains

        d_beta,j=beta_(j+1) U_j(E_j+M_j),

where only the actual new regular fluctuation response is eligible.
There is no extraction of beta(S_j M_j) and no beta of a full young
R/B/outer sum. The fixed-radius extractor and unprojected quantum
bound give only

A persistent marginal tag therefore permits a cumulative upper bound
C |a| sum_j g_j^2, which need not be uniform on a harmonic weak
trajectory. The draft neither deletes this driver nor incorrectly
concludes that the actual driver must diverge. The exact scalar driver
is likewise retained separately.

The specialized physical Wilson quantum marginal cancellation could
improve this part if it is separately registered for the SAME reference,
map, normalizer and cutoff. No such g^4 estimate is needed or inferred
in the present mature value lemma. A nonlinear queue or coupling
comparison still requires its own driver/arrival estimate.
