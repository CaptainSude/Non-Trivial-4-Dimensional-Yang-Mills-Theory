TURN75 -- THE NEXT CONCRETE MIXED-BOUNDARY ATTACHMENT
20 October 2026. history47. Proposed next proof target, with exact algebra.

This note identifies a specific comparison needed after the homogeneous
native q-core result. It does not assert that the comparison has already
been proved. The masked identity below is exact wherever its displayed
reads are admitted. In particular it does not evaluate a coefficient
across an excluded hard cutoff or turn a physical-null germ into a
boundary-local function without proof.

1. KEEP THE NEUTRAL SOURCE ROOT AND THE RAW SCALAR

Let F_(H,x) be the old native sourced output and L_(H,x) the chosen fresh
forward lift of the physical homogeneous output. Take a common complete
carrier refinement, retaining all source, frame, gauge, current and
localization reads, and define N_(H,x)=F_(H,x)-L_(H,x). This comparison
is between actual coefficient families; equality of a real supremum is
insufficient. The source root x is retained even if a coefficient is
field independent.

On a common admitted homogeneous physical completion zbar_x, equality
for EVERY external scalar profile implies the rootwise identity

                  sum_H N_(H,x)(zbar_x)=c_x.                (1.1)

If raw scalar terms are matched in the fresh lift, c_x=0. If only
field-normalized totals have been matched, c_x is the actual retained
source vacuum coefficient. It must be kept; it is not an error term.
For a more general comparison in which the right side varies with the
outer datum, retain that pointwise scalar as written instead of silently
declaring it a universal constant.

2. THE DOMAIN-SAFE MASK IDENTITY

Fix a discrete native branch and its regular region Omega. Let a_H be
the actual mask for a complete read to be retained as interior. For the
simple whole-read mask a_H=1_{H subset Omega}, put a_x=1_{x in Omega}.
All declared H contain x. Let z denote the actual native data. Assume
N_(H,x)(z) is admitted ONLY when a_H=1, and N_(H,x)(zbar_x) is admitted
for every term in its absolutely convergent comparison family.

The exact identity that uses only those admitted values is

 sum_H a_H N_(H,x)(z)
 = sum_H (a_H-a_x) N_(H,x)(zbar_x) + a_x c_x
       + sum_H a_H [N_(H,x)(z)-N_(H,x)(zbar_x)].             (2.1)

The proof is addition/subtraction on selected carriers followed by
(1.1). If a_x=0 then no H containing x can have a_H=1. If a_x=1,
a_H-a_x is nonzero only for complete carriers that leave Omega.
Consequently the first sum carries an explicit connection from x to
the boundary in its COMPLETE read support. Its completion/frame reads
must be added as well; they are not free or erased.

If every N_(H,x)(z) is separately admitted, an equivalent version is

 sum_H a_H N_(H,x)(z)
 = sum_H(a_H-a_x)N_(H,x)(z)+a_x c_x
       +a_x sum_H[N_(H,x)(z)-N_(H,x)(zbar_x)].              (2.2)

Formula(2.2) is NOT used when the purpose of a_H is to exclude an
inadmissible actual read. In that situation inserting its missing
N_(H,x)(z) terms would be an unjustified domain extension; (2.1) avoids
it. Masks with collars or eligibility types require the corresponding
root decision and the exact rule showing that unequal decisions have
a boundary-reaching complete determining set. No such rule is inferred
from a carrier's final name alone.

3. THE SPECIFIC READ-COMPARISON LEMMA STILL TO PROVE

For the last term of(2.1), the actual native (U,J) data need not equal
the homogeneous completion on a selected carrier. Both fields can be
small while solving different constrained/boundary problems. The next
target is a source-retaining complete-walk expansion of

           N_(H,x)(z)-N_(H,x)(zbar_x),                    (3.1)

on every actual selected read. It must have the following concrete
property: a term that is not zero contains a retained reconstruction,
constraint, gauge or localization path from its source/read to the
actual mismatch/boundary determining set. Short common equations and
boundary data must match exactly before the first changed read; long
terms retain their original decay and dated labels. The required norm
is the actual mixed native field/current/source coefficient norm,
including its local decoupling contours and all scalar coefficients.

This is a comparison between two specified sourced preparations. It is
stronger than scalar exponential locality of either one separately.
Native boundary versions of the elliptic/localization construction are
the plausible mechanism, but the TURN75 homogeneous q theorem does not
by itself establish(3.1) with this support property. In particular one
cannot use equality on the physical graph to delete its off-pair value.

A simple check makes the distinction unavoidable. An analytic pair
germ N(U,J)=J-J_phys(U) vanishes on its physical graph and is nonzero
at independent J. In gauge-invariant scalar form use a local trace
of (J-J_phys(U))^2 with all physical-current reads retained. At U=1,
J_phys(1)=0 and a nonzero small J makes this function nonzero. Physical
restriction alone says nothing about the distance of that nonzero
read from a boundary. The missing information is the actual comparison
between the native read and its homogeneous completion, not another
analytic identity theorem.

4. ACTUAL OWNER ASSIGNMENT AFTER THAT COMPARISON

Once(3.1) is represented with its complete changed-read paths, choose
one deterministic first hit of an actual boundary/raw component along
the retained connected support. Keep that owner, the original source
root, its original birth date, and all current roles. Ties can be broken
by a fixed ordering; their finite or geometric multiplicity must enter
the majorant rather than duplicate the same extracted small factor.

The ordinary arms outside the component retain their spatial decay.
The localized Cauchy/preparation loss at the owner is charged once as
an actual dated raw/boundary incidence. The enlarged-cost forecast
ledger of turn75_marked_ledger_tail can then be applied where its
owner/multiplicity and remaining-test hypotheses are verified. One must
not re-use a small integrated raw mass as a pointwise measure bound.
Nor can a later already-healed bulk source loss be charged to its old
bad ancestor merely because that ancestor existed. After it becomes
an admitted homogeneous core source, it must use the fixed-core q map;
new boundary reads require their own actual ownership.

This gives a precise next construction: compare and mask two complete
source preparations with the same weak completion, file the explicit
rootwise scalar, and send only the demonstrably boundary-reaching
difference to the dated owner ledger. Proving that sourced comparison
and its actual native typing is still necessary before claiming a full
mixed-class or original-law source trajectory.
