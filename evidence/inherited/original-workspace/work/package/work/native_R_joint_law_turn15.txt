1. The actual reconstructed branch variables and weight

Fix a finite regulator, a pre-replacement history h, and one selected large-
field component X. The history retains all old geometric labels, the past
integration variables needed to define them, the proposed reset domain
Lambda subset X, and its boundary/gauge conventions. Do not replace this
state by only a current coarse link configuration before taking conditional
probabilities.

Let E_k be a fixed set of independently oriented current links. Let E_Lambda
be exactly those links integrated by the replacement. Set

  x=V|E_Lambda,  e=V|E_k\E_Lambda.

Thus e contains crossing/boundary links unless the actual integral includes
them. This is the unambiguous meaning of untouched exterior. The domain
name Lambda alone does not decide a crossing-bond convention.

A finite additional label theta specifies the chosen frame, gauge tree G,
auxiliary tree T, and any genuinely uniformly averaged choices. The other
labels hidden by the ellipsis in the source formula remain part of h; they
are not automatically uniformly sampled.

The reconstructed reference reads e_D, D=X\Lambda with its complete boundary
slots, and constructs the minimizing extension V_Lambda(e_D). In relative
coordinates v' its output is

  Phi_(h,theta,e)(v')|E_Lambda = v' V_Lambda(e_D),
  Phi_(h,theta,e)(v')|E_k\E_Lambda = e.                       (1.1)

All products in (1.1) are the componentwise oriented-link group products in
the chosen frame. Inversion supplies the opposite link orientation.

The concrete Raw-II reference quotient is

  s_(h,theta,e)(dv') = Z_(h,theta)(e)^(-1)
     delta_G(v') chi_Lambda(v')
     exp{-g_k^(-2) A[zeta,U_(k,X)(v' V_Lambda(e_D))]} dv',     (1.2)

  Z_(h,theta)(e) = integral_(E_Lambda)
     delta_G(v') chi_Lambda(v')
     exp{-g_k^(-2) A[zeta,U_(k,X)(v' V_Lambda(e_D))]} dv'.     (1.3)

Here zeta is the real action cutoff, NOT an observable source. The minimum
U_(k,X) uses its full determining data and fixed boundary. Reference
definedness is required on the whole support of chi_Lambda. Only current
data in D are claimed as its external read by Raw II109033--109038; this
must be enlarged if the literal local minimum uses a further boundary
collar. No exponential locality theorem turns that complete read into a
strictly smaller support.

For a forest/tree gauge, delta_G dv' means the honest slice measure: set
the pinned independent tree links to 1 and integrate the remaining links
with product Haar. It is not a signed distribution. If the source G uses a
different constraint, (1.2) must instead include its exact positive coarea
measure; that identification cannot be inferred from the symbol delta.

2. Finite-regulator positivity, definedness, and the joint law

Define the reference-admissible exterior set A_(h,theta) by the following
concrete conditions: V_Lambda and U_(k,X) are Borel, real group-valued and
defined on the full reference cutoff support; zeta is real and bounded;
chi_Lambda is measurable, nonnegative and bounded; and it is positive on a
nonempty relatively open set of free slice links. The native gate is
chi_(k,Lambda); its implication of these conditions is a native attachment,
not proved by merely naming the gate.

Under these conditions, 0<Z(e)<infinity at every finite regulator. Indeed
the Wilson action on a fixed finite graph is bounded on all group-valued
configurations: |A[zeta,U]|<=C sum_p |zeta_p| with the prescribed mesh
weights. Therefore exp(-g_k^-2 A) is bounded above and bounded away from
zero for fixed g_k>0 and fixed regulator. The slice has finite Haar mass,
and the open free-link set has positive mass. This proves the denominator
claim directly; it does not prove a useful bound uniform in refinement.
Integrals of Borel nonnegative functions make Z and s measurable in e.
No analyticity assumption or Gaussian approximation is needed for this
finite-regulator probability statement.

Let tau_h(de,dx,dxi) be the positive pre-replacement branch measure. The
optional xi retains all old hidden variables. It can have arbitrary
correlations across the component and exterior. Define

  J_h(de,dx,dxi,dv') = tau_h(de,dx,dxi) s_(h,theta,e)(dv').    (2.1)

The old marginal is exactly tau_h. The new current field is Y=Phi_e(v').
After forgetting old x,xi the new marginal is

  m_h(de) (Phi_e)_*s_(h,theta,e),
  m_h(de)=integral tau_h(de,dx,dxi).                         (2.2)

This is EXACTLY the rule described in Raw I908--910 and157071--157074,
with the more precise Lambda integration supplied by Raw II. Total mass
is preserved. Hidden variables can remain in the joint history even though
they are integrated out of the effective current marginal.

An inadmissible exterior is not assigned the undefined quotient 0/0. If
tau_h is already supported on the admitted set, any probability-kernel
extension on its complement is harmless, including the identity kernel.
This statement does NOT introduce an unchanged rejected branch for a
larger input measure. Such a branch is part of a full rule only when the
rule explicitly specifies it, as in the reconstructed implementation B
below. An exterior with zero prebranch measure may be assigned any
probability kernel without changing (2.1); this is different from proving
the quotient everywhere or identifying a full native operation.

3. The outer 1/N and chi factor: exact completion, not an implicit probability

The reconstructed display multiplies (1.2) by

             (1/N) sum_(theta,...) chi_(k,Lambda).           (3.1)

The quotient alone has mass one; (3.1) need not. Two mathematically exact
implementations distinguish the issue.

Implementation A: already-resolved branches. Put all PRE-REDRAW-MEASURABLE
prefactors, old labels and chi_(k,Lambda) into tau_h BEFORE applying (2.1).
An output-dependent gate cannot be absorbed into this old measure; it
must be kept after redraw. Then (2.1) preserves
the mass of each branch separately, whatever that mass is. The omitted
nonqualifying branches remain unchanged. It is enough to have the actual
positive identity sum_h tau_h=M_pre on the augmented input space. No
pointwise assertion about (3.1) is made.

Implementation B: an explicit reconstructed step. For a fixed parent h,
let Theta_h be its finite set of uniformly sampled frame choices and
p_theta=1/|Theta_h| (or any specified nonnegative probabilities summing to1).
Let a_theta(V,xi) in[0,1] be the exact admission/eligibility gate, with
a_theta>0 implying reference admissibility. Then define

  K_h(V,xi;dtheta,dY)=p_theta [
      a_theta(V,xi) (Phi_e)_*s_(h,theta,e)(dY)
       +(1-a_theta(V,xi)) delta_V(dY)].                     (3.2)

For every input, K_h1=1. The labels record both theta and accept/reject;
thus even if a_theta depends on discarded x, the selected input measure
a_theta tau_h is the one whose x is integrated in (2.2). When a_theta is
the claimed exterior-only chi_(k,Lambda), it can be factored outside that
integral; this is the origin of the displayed prefactor in the reconstruction.
Equation(3.2) defines the reconstructed replacement PLUS its explicitly
chosen unchanged rejection branches, by direct Fubini. It is a concrete
complete scheme. It does not infer that the native rule has these rejected
branches. In implementation A, by contrast, extending an admitted branch's
kernel by identity outside its existing support does not change that
branch at all. These two uses of the identity kernel must not be conflated.

To identify (3.2) with the literal native formula one must check: N is the
normalizer for exactly the choices called theta; the ellipsis has no
additional unnormalized history sum; the nonqualifying branch is retained
with precisely 1-a_theta; and the native criterion is tested at this point
in the chronology. An integrated mass identity alone does not prove these
pointwise facts. Nor may a post-redraw first/second-class decision be moved
to the pre-redraw input.

If one only has positive branch measures on current fields whose sum is
M_pre, then posterior weights d tau_h/dM_pre give the same joint scheme
after exposing h. This can depend on the whole input law. Signed localized
activities cannot be used as those weights.

4. Several components and the order of the class decision

For disjoint changed sets Lambda_i, simultaneous independent draws are
valid if every reference external read D_i is disjoint from all Lambda_j,
j!=i. In the reconstructed claim D_i subset X_i\Lambda_i, this follows
from disjoint complete X_i. The old input need NOT be a product measure:
the joint replacement is tau(de,dx) product_i s_i(e,dv_i'), whose old
correlations are deliberately discarded and whose new marginal is
m(de) product_i s_i(e,dv_i').

If a minimum/collar read D_i meets another changed Lambda_j, independent
draws conditional on the FULL OLD state are still a valid possible
kernel. They no longer yield the displayed m(e) product_i s_i(e) law.
If instead the proposed reference factors read each other's NEW values,
their product need not normalize. For example, on two binary variables,
proposed normalized conditionals
s_1(y_1|y_2)=1_(y_1=y_2) and s_2(y_2|y_1)=1_(y_2=y_1) have product total
mass2. One needs the literal sequential kernel order or a joint normalizer.
Factorization of integrations in a rewritten expression alone does not
settle which case applies.

After drawing the new field, expose the first/second-class gate b(Y) and
1-b(Y) as a deterministic label (or a Bernoulli choice if the partition is
smooth). This preserves mass pointwise. Only then apply the source's
first-class gauge restoration. The second-class branch retains its slice.
Using the gate on OLD x would generally produce a different joint law and
different branch masses. Conditioning on a joint post-redraw gate may
also destroy the product independence of the initially drawn components;
the independence statement precedes such conditioning.

5. Exact gauge restoration on a finite forest, and its scope

Let B contain every declared fixed boundary vertex and every vertex
incident to a link declared fixed exterior. Choose a spanning forest G
covering all gauge-active vertices, with EXACTLY ONE anchor in each
component. A component meeting B must meet it at only
one vertex, and that vertex is its anchor; a component disjoint from B has
one explicitly declared additional root. All vertices of B are thus
anchors, possibly singleton components, and all transformations are 1 on
the anchors. The transformed links lie inside the declared changed region.
If a forest component contained two fixed anchors, its intervening path
holonomy could not in general be set to 1; that forest is inadmissible.

All independent anchor-to-anchor transports remain unpinned coordinates.
For this forest a unique anchored axializer sends any link field to the
slice W|G=1. More generally prescribe fixed oriented tree values t_e,
including the retained reference values V_Lambda when that is the actual
relative-gauge convention. For edge e=(u,v), in the convention
V_e^g=g_u V_e g_v^(-1), solving g_u V_e g_v^(-1)=t_e gives the recursion
g_v=t_e^(-1)g_u V_e. This fixes the same unique gauge.
Successive leaf integration and Haar invariance give a bijective change
of variables with unit Jacobian between full link variables and (slice
links with these fixed tree values, nonanchor vertex gauges). This is a
finite group-coordinate identity; no continuous logarithm is required.

For the relative coordinates of (1.2), write Y_e=v'_e t_e, with
t_e=V_Lambda,e fixed at the given exterior. Ordinary gauge action on Y
induces the TWISTED relative action

  (v'^g)_e = g_u v'_e t_e g_v^(-1) t_e^(-1).              (5.0)

The slice v'|G=1 is exactly the prescribed-value slice Y|G=t|G. Right
translation by t preserves product Haar, so the preceding tree argument
applies without a new Jacobian. One must randomize Y by its ordinary
gauge action, or equivalently v' by (5.0); randomizing v' by the ordinary
untwisted action would be a different operation unless the baseline is
tree-trivial in the same frame. Gauge invariance below means invariance
of the full Y-weight, equivalently twisted invariance of its relative form.

Consequently, for a gauge-invariant real weight w, the slice measure
w(W) dH_slice(W), followed by independent Haar vertex gauges g, has full
law w(V)dH(V). This proves a literal positive restoration kernel

              K_g(W,dV)=integral_H delta_(W^g)(dV) dg.       (5.1)

It fixes every gauge-invariant observable. It preserves the exterior only
with the boundary/incident-link convention just stated. If a root or
boundary transformation is left free, the changed region must be enlarged.

The source's first-class prose states the relevant gauge-invariance and
integrated equivalence. To identify its particular full-link representative
with (5.1), its G, residual gauges, boundary anchors and Haar/coarea factors
must match this finite-forest dictionary. For the reconstructed scheme we
choose that dictionary explicitly, so (5.1) is proved. We do not infer it
for every native delta symbol.

On the gauge-orbit quotient, (5.1) is simply the identity. Singular
second-class laws push forward to positive quotient measures without
difficulty. A Markov description on the quotient ALONE additionally needs
the reference selection and kernel to depend only on the input orbit.
Otherwise the correct state includes its frame and history labels; forgetting
them uses state-law-dependent conditional distributions. Gauge equivalence
against invariant tests does not by itself prove quotient transition
locality or reflection compatibility.

6. The concrete backward read and innovation consumer

On an accepted component and fixed theta,

  (Kf)(V,xi)= integral f(Phi_(h,theta,e)(v')) s_(h,theta,e)(dv'). (6.1)

It is independent of discarded x, but generally depends on every retained
datum used by V_Lambda, U_(k,X), the cutoff, or Z(e). A function supported
inside Lambda can therefore be transported to the full component collar.
The selector itself can read the history/geometry beyond that collar.
No assertion that K preserves a reflection half-algebra follows from(6.1).

Where the relative domain and slice measure are fixed and the ingredients
are differentiable in an exterior coordinate e, the exact derivative is

  D_e Kf = E_s[D_e(f composed Phi_e)]
              + Cov_s(f composed Phi_e, D_e log w_e),       (6.2)

where w_e is the unnormalized reference weight in(1.2). If a characteristic
domain or slice moves, its boundary/coarea derivative must be added; it
cannot be suppressed by citing(6.2). The normalized denominator is precisely
the subtraction producing the covariance. A bound for an unnormalized
operator does not give a uniform bound for(6.2).

The explicit chain from (3.2), (2.1), the post-redraw class label and (5.1)
is enough to apply the exact innovation ledger in
work/positive_channel_innovation_ledger_turn14.txt to THIS reconstructed
scheme. It is not enough to make its losses small. In particular:
  * rejection/class/frame randomness contributes its own variance;
  * oscillations must be bounded on the complete actual redraw support;
  * sequential or overlapping components require the actual kernel order;
  * no reference action is the conditional Wilson action merely because
    both are positive or use the same boundary data.

8. Final read/selection check and primary limits

The targeted primary check narrows, but does not eliminate, the read issue.
B122-II p357(1.3) specifies U0 by the LOCAL determining set B_k(Z),
with the datum obtained from the current V_k on Z\Lambda; p358(1.10)

claim. This note retains the complete finite collar as part of D until
that dictionary is verified. The reconstruction's other backgrounds U0
and U'' using seed-own retained data (Raw III18620ff) are different maps;
their existence neither proves nor refutes the reference's claimed read.

A backward finite-range causal cone would require a LOCAL CERTIFICATE
for selection too: every component whose redraw can affect S, and every
preparation, waiting-history, nested-component, and chi_(k,Lambda)
predicate used to decide that redraw, must be determined by the augmented
state on S enlarged by C M R_k current cells. The diameter of the changed
Lambda alone is insufficient. Primary II pp357--358 bounds the Lambda
under analysis by a 100M box in its stated scale. Primary B119 p255(2.3)
only says that a large-field component which fits a 100MR_j box is
rectangular; it does not say every possible component fits such a box.
Neither statement supplies the full local-selection certificate. Thus
the uniform-depth causal-cone conclusion is not claimed in this pass.

The mathematical conditional implication is simple and remains useful:
if every one-step backward observable read has physical enlargement
C r_k R_k, composition enlarges by at most C sum_k r_k R_k. Under a
geometrically decreasing earlier mesh and polynomial-in-age R_k this
sum is finite uniformly in the number of earlier steps. The missing part
is the literal native certificate, including the augmented labels, not
this geometric summation or the fixed-branch normalized replacement law.
