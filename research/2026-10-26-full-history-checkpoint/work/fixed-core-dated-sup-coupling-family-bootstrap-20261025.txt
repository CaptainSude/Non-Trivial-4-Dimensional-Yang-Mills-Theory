Let x_j be an admitted real baseline core sequence, x_j>=X. Assume its actual

         x_i>=x_j+lambda_*(j-i)-C0,  lambda_*>0.          (7)

 d_j=perturbed x_j-x_j,
 b_j=||perturbed B_(j+1)^c-B_(j+1)^c||_birth,

 b_j<=C_B(|d_j|+u_j)/x_j,

4. THE DATED-SUP CLOSURE

If X>=2C0, (7) implies x_i>=x_j/2 for i<=j. It also implies

 sum_(i<j) x_i^-2 <= C_sum/x_j,                          (10)

where, for example, the comparison with
sum_(r>=0)(x_j-C0+lambda_* r)^-2 proves (10) with a constant depending only
on lambda_* and the fixed lower floor. This is uniform in prefix length.

Fix D=2|zeta| and A=4C_B (increasing C_B to at least one if needed). Suppose
inductively |d_i|<=D and u_i<=A D/x_i at the previous dates. Each earlier
birth then obeys

 b_i<=C_B D/x_i+C_B A D/x_i^2.

Taking the supremum over i<j and using x_i>=x_j/2 gives

 u_j<=[2C_B+4C_B A/X] D/x_j <= A D/x_j                 (11)

once X>=8C_B. The bound does not use a dissipative recurrence for u_j.
It uses that an older coefficient was BORN at a no-smaller inverse coupling,
up to the fixed signed-stretch defect.

Using (9)--(11),

 |d_j-zeta|
    <=C_beta(1+A)D sum_(i<j) x_i^-2
    <=C_beta(1+A)C_sum D/x_j.                           (12)

Choose X so that C_beta(1+A)C_sum/X<=1/4. Then |d_j|<=3D/4<D, closing the
strict bootstrap. In particular

 |d_j|<=2|zeta|,
 u_j<=2A|zeta|/x_j,

All estimates are complex modulus estimates and therefore apply to a disc,
not only to a real perturbation. Select a constant c>0 so that 2c is inside
