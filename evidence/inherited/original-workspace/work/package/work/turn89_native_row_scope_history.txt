1. THE LITERAL ROW SURVIVES THE FIRST R

For the original fixed-slice field B, retain the original half integrals
 Z_+(B)=int exp(-S_+)dU_+,
 Z_F(B)=int F exp(-S_+)dU_+,
 Z=int w_B Z_+^2 dB,
 J=Z^-1 int w_B G Z_+ Z_F dB.
Here F is the actual positive-half time difference of the bounded spatial-flow smear; G is the original bounded boundary smear. The opposite-half factor Z_+, w_B, and the original normalization Z are part of this row. E F=0 is global stationarity, not conditional centering on B or on one native component.

Large-I printed194, (1.76), and printed201, (1.99)--(1.102), give the admitted fixed-choice joint
             tau_e(dx,dxi) q_e(dy),    int q_e=1.
The original source remains M_e(x,xi), with its earlier eliminated variables represented by the actual old raw coefficient when necessary. Completing the new classes and all normalized descendants eliminates q from this row. It does not turn M_e into the same source formula of y V_Lambda(e). This cancellation is valid on the complete finite positive old-record lift, conditional on original B, and not on an individually signed localized polymer coefficient.

Consequently a calculation using only the new reference conditional mean or variance cannot generate the leading original J. If an old half source is replaced by a current proxy, the additional term is literally
 int tau_e Q_e[(M_e-Mhat_e(y)) G_cont(x,xi,y)],
where G_cont retains the boundary/opposite-half and any unfinished native factors in the appropriate complete factorization. It cannot be replaced by1 until those factors really are completed. The first-R algebra is already established in TURN87 after-switch and TURN88 positive-lift notes; no new theorem is claimed here.

2. WHAT THE ACTUAL SMALL EXTERNAL EXPONENT DOES AND DOES NOT ESTIMATE

Large-II printed379--380, (1.71)--(1.75), compares an actual raw operator with a positive real same-slot baseline by an exponent sigma. For supplied tests K_e,K_0 on that common internal domain the exact difference is
 T_e K_e-T_0 K_0
   =T_0[(exp(sigma)-1)K_0]+T_0[exp(sigma)(K_e-K_0)].
The published scalar bound estimates the first term. It is useful for a bounded source whose same-slot identity and domain have already been supplied. It does not calculate the second term for the inherited original flow source, nor compare the original joint boundary law with a free boundary law. The original source also cannot be inserted a second time into a baseline which already contains its old mass or a remaining interaction factor.

TURN83's actual complete-action primitive is stronger than an arbitrary fixed-slot statement at its own scope: constrained stationarity, the complete source-rooted linear kernels, even frozen noise windows, and finite fourth polynomial marks give the g^2 mixed response with double profile differences and its fourth-order remainder. That result starts from the SAME complete fine-action reference on one admitted homogeneous primitive. The old F here is a bounded nonlinear flowed observable with earlier scalar/effective/source records. It has not been identified with that primitive's complete action insertion. The h^4 per-plaquette grading therefore cannot simply be applied to this inherited M_e. This is a source identity issue before it is a numerical power-counting issue.

3. WHY THE BARE COLLAR TAIL DOES NOT DISPOSE OF THE FIRST GENUINE R

The initial suggestion was to bound every relevant first-R contribution by a superpolynomial bare Wilson weak-collar probability. A direct primary check rules out treating that suggestion as already attached.

Large-I printed177 defines eligible R components by BOTH:
 (i) size at most100 MR_k;
 (ii) no fresh interior large-field regions during the preceding N RG steps, with the earlier contained regions obeying the size condition at their proper scales.
The text also explains the accumulated ten-layer growth and the earlier rectangular regions. Printed179--180 then builds the actual determining data from that previous chronology. Thus the first eligible R is not just the first bare Wilson plaquette or collar test. It already carries regular integrations, raw records, and their actual cuts.

The actual original-law theorem in polylog_box_collar_turn37.txt gives a small probability for a specified BARE weak collar and, on that event, control of the first ordinary averages with their complete footprints and common-frame links. Its stated exclusions include the native fluctuation chi test and later history predicates. polylog_box_native_matching_turn37.txt Section8 also retains the actual original numerical coarse datum and root gauges. Neither statement proves that an eligible first-R history event is contained in that bare bad event, or that the current source read has survived every previous replacement.

For a TRUE complete original-lift event E and |F G|<=1, the useful real estimate |E_W[1_E F G]|<=P_W(E) is immediate. But it may only be applied to the very event whose original-lift probability has been bounded. The TURN62 first-class insertion census is not a count of every basic-R redraw; low-success second-class outcomes remain. No such relabelling has been made in this check.

4. ALTERNATIVE COARSE PROBES: THE SPECIFIC REMAINING ATTACHMENT

An actual forward original coarse read phi(C_a U_0) passes unchanged through regular fibers which retain that SAME read. Large-I printed194 explicitly removes interior average restrictions before the reference redraw, so it is not generally equal to phi(C_a U_current) after R. The exact old read can always be retained passively; its conditional coefficient then remains to be estimated. This is the already documented TURN63/66 distinction, not a new obstruction.

One may instead DEFINE an original bounded observable by backward averaging an admitted terminal native test. This removes an inverse-record identity by changing the definition, but no physical lower bound follows. A reference-centered current test f_e-Q_e f_e has zero original pullback on each old record. An uncentered pullback may depend only on retained exterior data. Moreover, a local current test does not automatically yield an original positive-half observable, because the native global determining/minimum reads have not been proved to stay within that half. An actual same-half-local construction and a nonvanishing original boundary channel would still be required. No alternative probe with both properties was obtained here.

The current native input does not yet supply its nonzero leading term and cutoff-uniform error. This is a negative inventory finding, not a no-go theorem for Yang--Mills or for the bounded flowed probe.
