  0<=m_i-i<=C1+C2 log log gamma_i.                    (B)

5. FINITE-PREFIX COUPLING COMPARISONS FROM BLOCK DRIFT

No primitive monotonicity is required for the following comparisons.
Suppose |gamma_{n+1}-gamma_n|<=D and every completed aligned q-block
has gamma_j-gamma_{j+q}>=d>0. For arbitrary m<n, deleting the two
incomplete end blocks gives
  gamma_m-gamma_n >= (d/q)(n-m)-C_q,
  gamma_m-gamma_n <= D(n-m),                          (J)
where C_q=2qD+2d is sufficient. Hence, for gamma_n>=Gamma>2C_q,
  g_n/[1+D g_n^2(n-m)]^(1/2)
       <= g_m <= [1-C_q/Gamma]^(-1/2) g_n.           (K)
For any prescribed beta0>0 choose Gamma so the last multiplier is at
most 1+beta0. This gives near-monotonicity with arbitrary fixed slack,
even if some primitive increments have the wrong sign.

Put t_n=log gamma_n and h=n-m>=1. Since gamma_m<=gamma_n+Dh,
  t_m/t_n <= 1+log(1+D h/gamma_n)/log gamma_n
            <=1+D h/Gamma                            (L)
for Gamma>=e. The corresponding lower ratio is
  t_m/t_n >=1+log(1-C_q/Gamma)/log Gamma.
For each fixed p>=0, epsilon_n=A g_n (log gamma_n)^p therefore satisfies
  epsilon_m/epsilon_n
    <=(1+beta0)[1+D h/Gamma]^p
    <=(1+beta0)(1+D/Gamma)^p h^p
    <=(1+beta0)^2 h^p,                               (M)
after a further weak threshold choice. This is the explicit structure
of CMP119 (2.8), whose middle and final expressions are legible in the
primary text. The same calculation applies to every fixed logarithmic
cutoff exponent and to alpha0,alpha1. For the rounded scale
  R_n=ell^ceil(log_ell[(log gamma_n)^r]),
one has
  R_m/R_n <=ell [1+D h/Gamma]^r.                      (N)
At one primitive step, the unrounded scales have ratio between
ell^-1 and ell once Gamma is large. Consequently R_{n+1}/R_n is one
of ell^-1,1,ell, so the physical birth partition sizes ell^n M R_n
are nested ell-powers. This verifies the partition compatibility used
by the source without assuming primitive monotonicity.

6. CONDITIONAL STRETCHED-LOG SUM; NOT A BOUND ON R'' RENEWAL

This refinement is useful when a later finite prefix costs a polynomial
in gamma. It avoids choosing a source power P AFTER fixing constants
which might themselves depend on P.

Fix all source geometry and exponents first. Suppose each GENUINELY NEW
healed birth has its actual stronger bound
  t_i <= C gamma_i^D exp[-c(log gamma_i)^p],  p>1,        (O)
in its reserved source norm. To use the calculation below for a complete
descendant family, additionally assume that the TOTAL transport from each
genuinely new birth to the endpoint costs only the polynomial age factors
specified below. This extra ancestry/renewal estimate has NOT been proved
for the actual R'' recursion. Retaining an ancestor label does not prove it.
The factor gamma_i^D allows seed conversion,
fixed field/source Cauchy losses and logarithmic factors. CMP122-II
(1.100) supplies this form for new R' with its fixed p0(g); an annular
tail has the analogous p=2t>1. This assumption is NOT imposed anew on
the R'' descendants.

The all-age STATIC estimate in Sections1--2 charges only a fixed
polynomial in the age, the birth/end radius ratio, and gamma_i, after
the canonical h^4 and old-root count cancel. For endpoint gamma>=Gamma,
the drift comparisons (J) put gamma_i between fixed multiples of
gamma+(k-i), up to a fixed additive buffer. Hence its full sum is at most

 C sum_(a>=0) (gamma+a)^D' exp[-c1(log(gamma+a))^p],      (P)

where c1 can be any fixed number below c once Gamma is large enough.
The bound is uniform in the number of earlier scales. To estimate it,
compare the eventually decreasing summand with its integral and put
u=log x. For every c2<c1, and sufficiently large Gamma,

 integral_(gamma/2)^infinity x^D' exp[-c1(log x)^p] dx
   = integral_(log(gamma/2))^infinity
                exp[(D'+1)u-c1 u^p] du
   <= C exp[-c2(log gamma)^p].                           (Q)

For a direct proof of the last inequality, first absorb (D'+1)u into
an arbitrarily small fixed fraction of u^p. The derivative of the
remaining negative exponent is bounded above by -1 on the tail;
its integral is bounded by its value at the lower endpoint. The fixed
shift log(gamma/2)-log gamma is absorbed by the remaining coefficient
slack. The finite sum/integral discrepancy obeys the same bound.

Consequently any family satisfying BOTH the birth bound and the extra
total-ancestry bound, with fixed polynomial normalizations included,
has exp[-c2(log gamma)^p] suppression. Sections1--2 instead sum the
actual complete R^(i)=R'+R'' births using their established fixed-power
bound; they do not establish this extra ancestry hypothesis.
If its bounds hold on the admitted fixed constant-source disc, Cauchy
for any fixed source order only adds its fixed inverse-disc factor.
The same conclusion therefore holds for that whole-history derivative.

Over n<=C_* log gamma further steps, a rough fixed-step bound C_0^n,
root counts, and fixed polynomial packet sizes cost gamma^D''. The
same estimate absorbs this loss by decreasing c2 once more. All
constants and exponents are fixed BEFORE increasing the weak floor.
