3. EXACT CONTINUED-TEST DIFFERENCES: WHICH COMPARISON IS BEING MADE?

For the rejected coordinate switch alone, let nu=Psi^*tau and use the full transported original row. Then

 int nu (M_ab o Psi) G_new
        - int tau M_ab G_old
    = int tau M_ab [G_new o Psi^{-1}-G_old].             (3.1)

If G_new=G_old o Psi, this is zero including all cuts and scalar factors. If a comparison freezes a numerical future test instead, its actual defect is the bracket in(3.1). It is incorrect to retain only a cutoff sub-bracket while other factors are being transported exactly. On the complete positive ancestor from the frozen sibling producer, all baseline original density factors are already present. A test cannot insert those factors a second time; a raw factorization needs its genuine relative weight, with zero-support pieces retained.

For a genuine variation of the reference parameter e, at one fixed actual relative slice/window and fixed g_k, differentiation gives

                 -g_k^{-2} Cov_qe(G_e,dot A_ref).        (3.2)

Thus the old source row contains int tau_e M_ab times the right side, together with any genuine old-measure/source derivative if those also vary. Normalization cancels the covariance for tests independent of y. Neither(3.1) nor(3.2) asserts that an arbitrary later history is uniformly Lipschitz. 4. WHAT THE PUBLISHED SCALAR MAJORANTS DO CONTROL

Large-II printed379 states that, in the actual(1.71) representation, only the B quadratic form and V(X-tilde) depend on the declared external(U,J). Expanding these around its admitted regular real G-valued baseline produces an extra exponent sigma, while the internal variables/history catalogue remain those of(1.71). The first-order bound is a fixed native constant times

      M^d R_k^(d+2) p_1(g_k)^2 q_0(g_k) g_k,            (4.1)

with the source's fixed B_3,A_1,C_0 factors. The V contribution has the same type of bound after its complete connections to B0 union(Gamma_k'' intersect Gamma^X) are resummed. This is a native external-domain statement. It is not a bound on arbitrary real old B-coordinate motion or on an unprovided original-record complex inverse.

Writing T_e for this raw operator and T_0 for its positive real comparison, the literal identity and bounds(1.73)--(1.75) are

 T_e F = T_0(e^sigma F),
 |T_e F| <= (T_0 1) sup exp(|sigma|)|F|,
 |T_e 1| >= (T_0 1) exp[-2 sup|sigma|],
 |(T_e1)^(-1)T_e F| <= exp[3 sup|sigma|] sup|F|.          (4.2)

The lower bound is at the paper's admitted SMALL-sigma domain; it is not a general inequality for arbitrary complex sigma. The operator sum in(1.71) also acts on the residual exponential in(1.72), as the paragraph directly below(1.72) emphasizes. One must not replace it by its mass before that read.

For two supplied tests on this common internal domain, put K_e=F_e G_e. Exact subtraction gives

 T_e K_e-T_0 K_0
     =T_0[(e^sigma-1)K_0]
          +T_0[e^sigma(K_e-K_0)].                       (4.3)

If s=sup|sigma|, the first term is bounded by
 (e^s-1)T_0|K_0|.
The second is bounded by e^s T_0|K_e-K_0|. This identifies the missing quantity, rather than hiding it inside the symbol F. If K is fixed and uniformly bounded, (4.2) already solves the fixed-slot problem. If its old-source reconstruction or continued future test changes with the external field, the second term requires its own actual-domain estimate. Real bounded original plaquettes give a finite real bound at a fixed regulator, but not automatically its joint complex continuation, source-carrier norm, or cutoff-uniform physical census.

For real sigma, normalized comparison has the sharp convention

 |Q_e K-Q_0 K| <= 2||K||infty tanh(osc(sigma)/4).         (4.4)
This is the TURN53 fixed-slot response sharpened in TURN87; it is not a new source-entry theorem. For the reference in(3.2), an existing bound is

provided the same domain and supplied fixed test bound apply. The actual derivative/read costs and root census remain in these quantities.

Bounds(1.68)--(1.69) control retained scalar interaction pieces; the subsequent positive estimates for T_0 1 control the raw mass. 5. FIXED FORWARD-COARSE ORIGINAL OBSERVABLE: A CONCRETE LIMIT

A proposed alternative is F_a(U0)=phi(C_a U0), where C_a is a genuinely defined original forward coarse map at a fixed physical stop. On an exact regular coarse fiber whose retained datum is that SAME C_a U0, F_a is a fixed external test; inheritance through those exact fibers is trivial. This avoids an inverse-record problem on that portion of the history. The definition of C_a on the full original field support, its actual native equality, gauge covariance and complete read must be supplied, rather than assumed from a weak-chart ordinary average.

It does not survive a basic R as the identical current formula merely by being a forward average. Large-I printed194 says explicitly that the variational construction first holds M^h(U_k) fixed and then removes the average restrictions on Lambda. The current Vk|Lambda is integrated out. The reference(1.100) fixes exterior data and its axial gauge, but contains no delta matching the new interior averages to their old values. At stop k itself this already replaces the very Vk variable on which a coarse observable may depend. At earlier dates it can change a later ordinary average if that average reads the replaced interior.

The original C_a U0 can always be kept passively in(2.1), with its original law. After integrating old slots its mark is the corresponding conditional coefficient. It is not thereby equal to C_a of the new current field. If its COMPLETE forward read avoids every replacement, equality persists; obtaining a useful original-law probability/estimate of this protected-history event is an additional task. The current regular label is not the event of no previous replacement. Both eventual first- and second-class components undergo the earlier basic reference redraw, whereas TURN62 insertion counts control only first-class outcomes. The success-weighted all-birth bounds of TURN64 do not supply an unconditional count of all low-success second-class replacements.

This precise obstacle was already recorded in physical_coarse_variance_turn66.txt Sections6--8 and observable_history_transfer_turn63.txt Sections1,3--5. In particular, the actual native reference can have a nonconstant current cycle test f_e(y), but G=f_e-Q_ef_e has Q_eG=0 for every old record. Its original pullback vanishes despite positive reference variance. A fixed physical coarse observable remains a legitimate direction, but does not bypass the native reference replacement by fiber constancy alone.
