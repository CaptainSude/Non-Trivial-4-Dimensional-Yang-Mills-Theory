SCOPE

The native regular construction stores a newly integrated coefficient on its
original independent-(U,J) domain. Its later static reads can be prepared
directly by the original near/far construction. There is no algebraic reason
to replace this coefficient at every later date by a fresh ordinary coarse
function. This note gives the exact dated expansion and the estimate needed
to use that organization. Native source attachment is supplied only at the
scope explicitly verified in the TURN77 gauge/history notes. Live boundary
operators and full positive histories are not included by this algebra.

The main improvement over a repeated contraction argument is that a fixed
Taylor price is paid ONCE for each old birth in each requested preparation.
One does not compose a radius-loss bound once per elapsed scale. The price
may be large; exponential decay with age makes its convolution finite.

1. EXACT DATED EXPANSION -- INCLUDING THE INHERITED SOURCE

Fix the unmarked sequence of normalized regular integrals. At step j let
T_j=S_j+Q_j be its linear one-source map, with the literal same-read static
operator S_j and normalized noisy-minus-static operator Q_j. In particular
Q_j includes the denominator derivative of the original normalized integral.
Define X_0=F and X_(j+1)=T_j X_j. Define the NEW birth

                  B_(j+1)=Q_j X_j.                              (1.1)

For n>i put S_(n,i)=S_(n-1)...S_i, and S_(i,i)=Id. Then, identically,

 X_n=S_(n,0)F+sum_(i=0)^(n-1) S_(n,i+1) B_(i+1).                (1.2)

Proof: insert X_(n+1)=S_n X_n+B_(n+1) and induct. No commutation of
S and Q and no geometric-series truncation is used. A path with several
quantum operations occurs in exactly the birth corresponding to its LAST
quantum operation; earlier quantum operations are already inside X_i in
(1.1). Using Q_i F instead of Q_i X_i would omit those paths. Adding a further
expansion of B_i alongside that same complete B_i would double count;
replacing B_i by an exact expansion is legitimate.

All functions in (1.2) include their source vacua. A subsequent split
B_i=v_i+b_i R_i+E_i is an exact filing; v_i is retained in a separate scalar
ledger, and E_i is a complete own-field germ. The scalar cannot be dropped
when computing a mixed derivative or comparing different histories.

Equation(1.2) alone does not identify a composition of arbitrary minimizing
maps with a single minimum. For the native application the static product
must be the actual later read of the stored birth, with its prescribed
current companion, data and gauges. The literal B109/B119 old-input
preparation supplies that read at its admitted scope. A new artificial
reconstruction or rehatting does not follow from the algebra.

2. ONE PHYSICAL REFERENCE WITHOUT AN ADAPTIVE=ORDINARY IDENTITY

Use a fixed original fine plaquette set and its gauge-invariant action
density h_p(U). On aligned source grids let I_(i->0) be tensor multilinear
interpolation to that fine grid, and let A_p average the four plaquette
corner values. Define the reference as a function of the SAME fine field:

 R_i(f_i;U)=sum_p [A_p I_(i->0)f_i] h_p(U).                      (2.1)

Any fixed physical normalization is included on both sides. If
f_i=I_(n->i)f_n, the exact interpolation identity gives

                  R_i(f_i;U)=R_n(f_n;U)                         (2.2)

for every U. It is valid in particular at an adaptive minimum. It does not
assert that this minimum equals an ordinary one. At an actual static step,
both reference expressions are evaluated at the SAME prescribed fine-field
read, so (2.2) telescopes their physical values exactly.

This identity is not an analytic admission theorem. Complete plaquette,
interpolation, gauge and current footprints still belong to the reference
source. The born coefficient must use the corresponding native Maxwell
normalization. For a complete jointly covariant neutral scalar family this
normalization is scalar. An individual carrier, a fixed asymmetric profile,
or an unsummed pair of source/output roots is not scalar by itself.

Only a COMPLETE constant reference matching the physical Gaussian action
has the rank cancellation used below. A masked action, variable-coupling
precision, or deleted crossing term must not be substituted for that input.

3. QUANTITATIVE HYPOTHESES FOR THE REGULAR CORE

Set q_j=g_j^2=1/gamma_j. Assume gamma_j>=G>=1 and

                 |gamma_(j+1)-gamma_j|<=D.                       (3.1)

M_j=max_(0<=i<=j)|alpha_i|. Start with no old residuals. Let w_i be the

 K(t)<=C_K(1+t)^m L^(-sigma(t-1)),  L>1, sigma>0,
 P_j<=sum_(i<j) K(j-i) w_i.                                  (3.2)

Assume the new birth and marginal increment satisfy

 w_j <= C_b q_j (|alpha_j|+P_j),                              (3.3)

   <= C_a[(q_j^2+tau_j q_j)|alpha_j|+(q_j+eps_j)P_j].         (3.4)

Here tau_j>=0 retains the actual Gaussian-window and reference-extraction

These are quantitative hypotheses on the SAME expansion, not on independent

4. VOLTERRA BOUND: USE THE OLD BIRTH SIZE BEFORE GRONWALL

The signed step bound implies, for i<j and t=j-i,

 q_i/q_j=gamma_j/gamma_i <= 1+Dt/G.                           (4.1)

This linear-in-age comparison needs neither monotone running nor a
per-step exponential ratio. Put

 kappa_* = sum_(t>=1) K(t)(1+Dt),
 B=2 C_b kappa_*.

Both are finite, independent of the ultraviolet depth. Choose the weak
floor G>=max(1,B). Then simultaneous finite induction proves

               P_j<=B q_j M_j,
               w_j<=2 C_b q_j M_j.                          (4.2)

Indeed P_0=0. If the bounds hold before j, then q_i<=1/G and
w_i<=C_b q_i M_i(1+B/G)<=2 C_b q_i M_i. Since M_i<=M_j,
(3.2) and (4.1) give P_j<=2 C_b kappa_* q_j M_j=B q_j M_j.
Equation(3.3) now gives the asserted w_j. This proves (4.2) without
presupposing a bound on M_j. The factor K(1) may be large; a larger fixed
G absorbs it. There is no need for the one-step static map to contract.

Substitute (4.2) into (3.4). With

          a_j=q_j^2+(tau_j+eps_j)q_j,
          A_N=sum_(j<N)a_j,

one obtains |alpha_(j+1)-alpha_j|<=C a_j M_j and hence

 M_N<=exp(C A_N),
 |alpha_N-1|<=C A_N exp(C A_N),
 P_N<=B q_N exp(C A_N).                                    (4.3)

The reference cannot vanish if the second bound is less than one. This is
a coefficient statement. It is not an original-law variance lower bound.

5. DEPTH-UNIFORM SUMS AND THE ACTUAL TYPES OF ERROR

Suppose in addition gamma_j>=G+d(N-j), d>0. Then

                  sum_(j<N)q_j^2<=1/(dG).                    (5.1)

A Gaussian-window error tau_j<=C q_j is therefore harmless in (4.3).
For tau_j containing exp[-c T_j^2], that bound must be checked for the
actual fixed window T_j; it is not a consequence of parity alone.

If eps_j<=E exp[-c Q_(j+1)], Q_(j+1)=L^(N-1-j)Q_end, then

 sum_(j<N)eps_j q_j
 <= (E/G) exp[-c Q_end]/(1-exp[-c(L-1)Q_end]).                (5.2)

The same estimate applies to an additional finite-period part of tau.

(5.1) by G+dr, and in (5.2) use the stronger period L^r Q_end and floor
G+d(r+1). These are tails of the declared recurrence, not convergence
of different regulated measures or compatibility of their observables.
