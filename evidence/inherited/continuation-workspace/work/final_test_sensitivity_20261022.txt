2. THE EXACT CONNECTION RETRACTION

Fix the native coordinate/block convention s. Let pi_k map a fine vertex
to the root of its containing k-block, on the current lattice of spacing1.
For an oriented fine bond b, its endpoints have either the same image or
the endpoints of one current bond c. B119(1.3), with k-blocks substituted,
says exactly

       (Q_k^{s*}v)(b) = 1, or v(c), respectively.             (A)

In other words Q_k^{s*}v is the pullback connection under this graph map.
The group value along any fine path is the ordered coarse path value
obtained by projecting its vertices and removing stationary steps.

Take a grade-j ordinary averaging row, 0<=j<=k. Compatibility of the
native partitions means that each j-block is wholly inside one k-block.
The full path Gamma_(c,x) used in CMP98(42) lies in the union of the two
adjacent j-blocks of its output bond c. It runs from the first root to a
point of the first block, crosses to the corresponding point of the
second block, and returns to the second root. Its projected path is
therefore constant if both j-blocks have the same k-parent, or is precisely
the single oriented current bond between their two k-parents. This
projected path is the same for EVERY averaging point x, and is also the
projection of the reference contour c in(42).

Thus every logarithm in(42) is log(1)=0. Its normalized average is zero,
and the output is exactly the common path value. Induction through the
ordinary averaging composition(43) proves

       M_j(Q_k^{s*}v)(c)
          = 1 or v(pi_k(c_-),pi_k(c_+)).                     (B)

This is an identity of group products, not a smooth-input estimate. It
does not accumulate a loss per averaging step, and never differentiates
the discontinuous fine injection. The logarithms used in this identity
are always at the identity, independently of the individual v(c).

Every row of the actual helper determining data M_B(Q_k^{s*}v) is one
of the rows in(B), by B119(2.11). The claim includes incident rows: both
blocks and the complete path read are retained when a bond has only one
endpoint in the determining set. Truncating a path at a helper boundary
would define a different operation and is not done here.
