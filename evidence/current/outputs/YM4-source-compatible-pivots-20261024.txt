RESULT

There is a concrete native subclass in which bounded, nonanalytic
source coordinates can be held fixed while the outer coarse datum
varies: each affected averaging row must have an unused private
interface bond outside the source's COMPLETE physical link read P.
Choosing that bond as the pivot gives a genuine nonlinear constrained
rechart. The source is then R(y_P), independent of the outer parameter
at fixed y_P. Original product cuts become explicit moved domains;
none may be discarded. The exact density includes the new coarea
factor and every original scalar/current/gauge/Haar term.

This supplies the native coordinate mechanism for a proposed fixed-
source-variable analytic projection. It does not by itself prove the
rare-domain comparison, a bounded normalized complex kernel, or
analyticity of a full native source on a fixed physical radius.
A shrinking complex radius of order g divided by a polynomial read
price is plausible and is the intended target; it is distinct from
the old fixed-radius analytic source module.

The full first hybrid/canonical read W may contain complete averaging
rows. That is a real obstruction to making all its physical coordinates
free by any pivot choice. Coarsening can remove the combinatorial
obstruction for a FIXED original read, but does not prove that an
already integrated source has that read or preserve all analytic
estimates automatically.

1. THE ACTUAL SINGLE-STEP AVERAGE HAS MANY PRIVATE CANDIDATES

Work on the actual current input lattice, with the fixed native odd
block size L and its prescribed partition into blocks B(y). For a
coarse bond c=(y,y+L e_mu), let Gamma_c be the positively oriented
input bonds crossing the common interface from B(y) to B(y+L e_mu).
It has L^(d-1) members, d=4. Every such bond is private to that coarse
row in the following exact geometric sense:

 the row average at c may read Gamma_c;
 no OTHER coarse averaging row reads any member of Gamma_c.          (1)

Indeed B109(0.11)--(0.12) uses endpoint contours entirely within the
two endpoint blocks and a translated straight length-L middle path
joining them. Endpoint contours never cross a block interface.
The middle path crosses only the interface of that particular c.
The anchored reference path c has the same property. Thus (1) holds
for the nonlinear row, not only its linearization. Distinct Gamma_c
are disjoint. The native b0(c) is one member of Gamma_c; its being
the central member is convenient, not needed for the finite implicit
inversion below.

At the joint flat field, linearizing the anchored-log formula cancels
its inner reference-path subtraction against the outside reference
path. The result is the ordinary uniform average of the full path
integrals. Each middle path crosses Gamma_c once. For a fixed member
b of Gamma_c, exactly L of the L^d starting sites have the matching
transverse coordinates. Thus for the PHYSICAL log of the group
average,

 D_(a_b)[ log bar(exp(i a))(c)/i ] at0
                      = w_L I_color,  w_L=L^(1-d)>0.    (2)

Endpoint contour averaging changes no interface coefficient because
those contours stay in their own blocks. If the paper's linear Q is
defined with the additional factor1/L, its coefficient is w_L/L;
the actual constraint map is LQ and has exactly(2). Keeping this
normalization distinction avoids altering the physical coarse datum.

On a sufficiently small common physical/complex chart, the derivative
with respect to any fixed candidate b remains invertible, with inverse
norm at most C w_L^-1. This is ordinary finite-dimensional continuity
and analytic inversion about(2), with fixed L. The actual average is
holomorphic on the same near-flat anchored-log domain as before.
For nontrivial admitted background representatives use the matched
block frame and their spare near-flat chart, not an arbitrary global
log chart for rough physical fields.

2. A CHECKABLE SUFFICIENT SOURCE-READ CONDITION

Let P be the COMPLETE physical input-link read of a bounded source
R(V|P). Include any tree paths, local minimum determining variables
which truly enter it as physical link arguments, and all other source
arguments. A visible insertion support alone is insufficient. Assume

 for every coarse row c whose pivot must change,
                     Gamma_c minus P is nonempty.       (3)

Choose deterministically p(c) in that difference. Leave the old pivot
when it is already outside P; change it otherwise. Condition(3) can
also be imposed on every row, with no harm. All chosen pivots are
distinct and their constraint Jacobian is block diagonal by(1).

A simple sufficient cardinality condition is |P|<L^(d-1). A geometric
alternative is that P avoids at least one actual interface bond in
each affected row. For example a physical plaquette read, with its
literal four links and no hidden source dependence, satisfies the
cardinality condition for native L>11. A filled source box smaller
than one block can also satisfy it, but its position and full read
must be checked; its apparent diameter alone is not the criterion.

The actual first hybrid R(beta_W), including the deterministic tree
extension, has full physical read W. There is NO reason for(3) to
hold for its generally large filled box. In particular if P contains
the COMPLETE native read of a coarse row c, its physical average
bar V(c) is already a function of y_P. On the fixed constraint fiber
bar V(c)=Vout(c), those y_P cannot range over an outer-parameter-
independent open product. No alternative constraint chart can evade
that rank obstruction while keeping all of them independent.

Failure of(3) alone is only failure of this diagonal private-interface
constructor: other nonprivate variables outside P might sometimes
solve a coupled constraint system. The stronger complete-row example
is a genuine obstruction to ANY full source-coordinate submersion.
These two claims must not be conflated.

3. THE EXACT NONLINEAR CONSTRAINED RECHART

Fix the complete outer datum theta and original geometric history.
For each selected pivot p(c), solve the ACTUAL group constraint

                        bar V(c)=Vout(c;theta)           (4)

for that link, keeping all other physical links independent. By(1),
no selected pivot occurs in another constraint row. Equation(2) and
the finite holomorphic implicit function theorem give the unique
small solution V_p=Psi_p(v_free;theta) on a strict common chart.
All selected source links belong to the free coordinates by(3).

Write y=log V|P/i. These are PHYSICAL source coordinates, not the
old relative A coordinates. At fixed y the source is literally R(y)
and has no explicit theta dependence. For the remaining free links
one may use physical angles or the old background-relative coordinates
z; in the latter case their theta dependence is kept in the analytic
reconstruction. The source does not acquire it.

Only rows whose old pivot is in P require changing ownership. Let
T be the union of their complete two-block constraint reads, P, and
the old/new pivot sets, enlarged by the finite current/noise stencils
used in the original parametrization. The old and new coordinate
maps agree on free coordinates outside T if those coordinates are
left in their old form. The reconstruction and its Jacobian within T
are analytic and finite-read. In particular one does not perform a
global inverse of the precision or the minimum to change pivots.

The coarea factor is the exact Jacobian for solving(4), combined
with each physical link's Haar density and whichever coordinate
scalings have actually been used. Since the row Jacobian is block
diagonal, the new pivot determinant is the product of its actual
finite color determinants. The sign is fixed on the small real
chart, so its positive absolute determinant has a holomorphic branch
there. This is a reparametrization of the same constrained measure.
It is not permission to use the old coarea factor unchanged.

If the original current map was

 V=Phi_old(x;theta), x in original K=product B_r,

write the inverse correspondence on the overlap as
x=X(y,z;theta). The EXACT sourced coefficient becomes

 N_R(theta)=C_out(theta) integral_(D_theta)
                      R(y) J_new(y,z;theta)
                      exp[-H_new(y,z;theta)] dy dz,

 D_theta={ (y,z) in the new chart:
                X(y,z;theta) in K and all original predicates }.    (5)

Every old free-ball test, source-independent prior predicate and
remaining gauge factor is pulled back in D_theta or retained in the
complete density, according to its original allocation. The former
old pivots, now free, did not have independent old ball cuts; the
newly solved pivots did have such cuts if formerly free. Those old
conditions are still present through X. Outside the affected T all
old cuts remain their old fixed ones. Inside T the resulting moved
domain is generally NONPRODUCT. Formula(5), with its unmarked
version, is the exact raw identity; no integration domain has been
replaced yet.

The raw factor C_out includes the exact zero-noise stationary action,
gauge/Haar/scaling and coarea allocations and inherited normalizers.
The original denominator remains the original raw unmarked integral,
equivalently its original Z1s times those common outer factors.
It is not the normalization of a newly chosen product in y,z.

4. WHAT A FIXED-SOURCE ANALYTIC PROJECTION WOULD NEED

If one supplies a fixed product B_y times K_z in the new real
coordinates and a holomorphic complete density K(y,z;theta), then

 A_R(theta)=1/Z_original(theta)
          integral_(B_y times K_z) R(y) K(y,z;theta) dy dz            (6)

is holomorphic in theta whenever its numerator is locally dominated
and the exact denominator is nonzero. R need only be bounded and
measurable on the FIXED real B_y. It is not evaluated at complex
y and no derivative of R is taken in this argument. This elementary
fact is useful but does not establish the following native inputs:

 (i) the complete new density is holomorphic on the proposed common
     theta tube for every point of that whole fixed product;
 (ii) a normalized complex bound and zero-free domain for the EXACT
     original denominator hold there;
 (iii) the difference between D_theta in(5) and the chosen product is
     confined to an event with the required normalized rare bound,
     including its first/two parameter jets if those are requested;
 (iv) its complete carrier/localization support and original source
     contacts satisfy the intended analytic consumer's domain.

For a real rare-boundary comparison, the background center on the
source coordinates must be close to the chosen fixed y window. If
that window has physical radius O(g r), a sufficient center condition
is |V_center| in the same O(g r) chart with a strict margin. The
previous c epsilon0 outer box can be much larger than g r; it does
not automatically supply this new condition. Keep the resulting
outer selection and its complement, or choose a different explicitly
matched fixed window. A product centered at theta-dependent source
values would make R depend on theta again.

The inactive noise coordinates, exact determinant, inherited F0/T0,
physical-current/gauge terms and pivot Jacobian all contribute to
the normalized complex bound in(ii). A pointwise real convexity
bound alone is not such a zero-free complex theorem. At the finite
two-success scope the existing analytic ordinary catalogue may
supply part of it, but it must be registered for this numerator,
this rechart and this radius. No full native regularization theorem
is asserted in this note.

5. WHY A FIXED PHYSICAL ANALYTIC RADIUS IS TOO MUCH

A precise finite diagnostic separates real smoothing from a uniform
fixed-radius holomorphic source norm. For the normalized full-line
Gaussian kernel of variance g^2, let

 R_g(y)=eta k^-2 cos(k y), k=rho/g^2,

where rho>0 is fixed. Its real value, first derivative and second
derivative are bounded by C eta (for k>=1), and its first derivative
at0 vanishes. The exact Gaussian image is

 Q_g R_g(theta)=eta k^-2 exp(-g^2 k^2/2) cos(k theta).

At theta=i rho its size is asymptotic to

 (eta g^4/(2rho^2)) exp[rho^2/(2g^2)].                   (7)

Centering R_g or its output by the exact flat scalar does not remove
this growth. Thus merely bounded real C^{1,1} inputs, even with a
rare factor exp(-c log^p(1/g)), cannot be sent into a uniformly
bounded analytic class on a fixed physical radius by Gaussian
smoothing alone. This is a finite regularity diagnostic, not a
native Yang--Mills counterexample or a claim about the particular
hybrid's high-frequency content.

A shrinking tube rho_g of order c g divided by a polynomial in the
affected read avoids the exponential factor in(7) and costs only
polynomial inverse-g/read factors under finite-order Cauchy. That
is the intended analytic-projection target here. It must be kept
separate from a previously registered fixed-radius own-field Ward
module until a valid domain/conversion theorem attaches it. The
incoming eta can pay any FIXED polynomial loss at birth; this does
not pay arbitrarily many repeated losses without an actual recursion.

6. WHAT COARSENING DOES AND DOES NOT FIX

For a FIXED physical source read P of N bonds, a single-step private-
interface condition is automatic if N<L^(d-1). More generally, on
the nested native lattice the composite m-step constraint M_m has
superblocks of side L^m. An outer interface has L^(m(d-1)) fine
crossing bonds. Endpoint paths at every level stay in their relevant
superblocks. At flat, the derivative of the nested averages is the
product of their positive path-average maps; the coefficient of each
fine superinterface crossing bond in its own final row is

             w_m=L^[-m(d-1)],                           (8)

and it belongs to no other FINAL row. Equivalently, each nested
parallel path crosses that superinterface once; the uniform block
weights distribute total coefficient1 over its fine crossing bonds.
Anchored reference subtractions cancel at the linearized levels as
in(2). This is about the native COMPOSITE M_m, not a silent replacement
by a differently defined one-step averaging operation of size L^m.

Thus if L^(m(d-1))>N, each final row has an unused fine crossing
bond outside the SAME original P. Choosing
m=O(1+log_L(1+N)) removes this combinatorial obstruction, with
w_m^-1 bounded by a fixed multiple of 1+N. Its affected superblock
read has at most a fixed-degree polynomial size in N. A finite
implicit chart exists near flat for that composite constraint.
Uniform quantitative analytic radii additionally require tracking
the complete higher derivatives of the composite map; no such
depth-uniform bound is supplied by counting pivots alone.

This does NOT mean that the source after m successive integrations
still has the original physical read P. The newly proved ordinary
consumer generally produces a quasilocal function, and can detect
entire later constraint rows. Nor may one discard the intervening
success cuts, gauges, normalizers and contacts while replacing the
joint m-step integral by the final constraint. Eliminating intermediate
coarse deltas is an exact formal way to keep the original P in one
joint integral, but every intermediate cut then becomes an explicit
pulled-back domain factor. Its analytic and rare-boundary analysis
is a new problem.

Consequently log-read coarsening gives a concrete POSSIBLE algebraic
window for a fixed incoming source, not an already proved macrostep
regularization or an assertion that the current full hybrid fits a
one-step thin-read class. Thin physical originals provide a nonempty
single-step class; full first hybrid reads require more work.

7. A DIRECT CONDITIONING OBSTRUCTION FOR GENERAL SOURCES

In this section tr is the normalized SU(2) trace (1/2)Tr, so
1-Re tr(I)=0. Both plaquette functions below use this normalization.

There is an exact reason a general source class cannot be smoothed
merely by this conditional integration. Let P contain the complete
physical read of the coarse average around one coarse plaquette p.
Choose a bounded nonanalytic C^{1,1} function phi and set

 R(V)=eta phi(1-Re tr[bar V(partial p)]).

This is gauge invariant and has finite physical read. On the actual
coarse constraint fiber, bar V=Vout, hence

                 Q R=eta phi(1-Re tr Vout(partial p))    (9)

EXACTLY, independently of the action or noise. Choose, for example,
phi(t)=(t-a)_+^2 with a strictly inside the admitted plaquette range,
and smoothly bound it outside that range. It is C^{1,1}, is constant
near the flat point when a>0, and remains nonanalytic across t=a
after integration. No normalization or source cancellation repairs
this elementary conditioning fact.

There is also an obstruction at the FLAT point itself, suggested by
the root and checked here. Put q(V)=1-Re tr[bar V(partial p)] and,
near q=0, use the SOURCE

 R(V)=eta q(V) sin(log q(V)) when q(V)>0, R(V)=0 at q=0,

with a smooth cutoff outside a small q interval. The scalar function
q sin(log q) is not C1 as a function of q at0. The SOURCE is nevertheless
C^{1,1} in the physical link coordinates: q>=0, |Dq|<=C sqrt(q),
|D2q|<=C, the first derivative of q sin(log q) is bounded and its
second derivative is O(1/q). Hence the physical gradient extends
continuously to0 on q=0 and its Hessian is bounded off that zero set.
Along each physical coordinate segment, the analytic q has isolated
zeros or is identically zero; integration of that uniform Hessian
bound gives the Lipschitz gradient through the zeros. In particular
DR(1)=0. A small curvature path with q~c t^2 has the behavior
eta c t^2 sin(2 log|t|+log c+o(1)), which has no second derivative
at0 and no analytic neighborhood there. Exact conditioning(9)
preserves this same function of the OUTER coarse plaquette. Thus
the universal real C^{1,1} class cannot acquire even a shrinking
flat analytic tube when it contains a complete constrained-row read.
This is a source-level C^{1,1} statement, not a false claim that the
scalar phi itself is C1 at q=0.

This is a counterexample to a proposed UNIVERSAL smoothing inference,
not an assertion that the actual rare hybrid has this form. It
explains why the source-compatible submersion/read condition is
substantive and why sources depending on full constrained rows
need a different argument. Together with(7), it identifies two
different gates: genuine source-direction randomness and a usable
complex radius/norm for the resulting analytic projection.
