FRESH-RADIUS COMPARISON: CAUSAL DRIFT BOOTSTRAP
25 October 2026. Conditional bridge; no continuity theorem asserted.

PURPOSE AND STATUS

The regular-comparison theorem assumes signed bounded increments and a
positive lower stretch bound for the actual weak prefix. It would be
circular to use a next-step estimate that already assumes those same
bounds at the unknown next coupling in order to prove them. This note
gives a causal way to obtain that estimate from the current prefix only.

The analytic comparison and Gaussian identification remain explicit
premises. In particular, this note does not certify that an earlier
native Gaussian heat calculation matches the current precision, nor
that the full RT coupling is continuous across partition/cut changes.
The numerical implication below is independent of those questions.

1. INPUTS

Let an actual homogeneous weak step be defined for a state at date j
with x_j=g_j^-2 >=Y. Use a_j=c x_j^-1/2(log x_j)^q. The state includes
all coefficients, cuts and partitions needed to perform the original
step; the coupling need not be a memoryless function of x_j.

(A) On any already generated prefix 0,...,j satisfying

 x_i>=Y, |x_(i+1)-x_i|<=B,
 x_i-x_k>=lambda(k-i)-C0  (0<=i<=k<=j),                         (1)

the common-fresh comparison and actual full homogeneous R import give

 ||D_E,j||_Bj <=A x_j^-s,  ||M_j||_Bj <=R_* x_j^-s, s>1.        (2)

Here Bj is normalized by a_j^2. For the first bound, apply the existing
finite-horizon comparison with horizon j. Its terminal orbit norm is
exactly the Bj norm, so no unconstructed future occurs in (2).

(B) The complete source map and its scalar/localizer contours have the
already proved image and compiler estimates with an AUXILIARY target
radius a_j at grade j+1, and input radius a_j at grade j. This is the
equal-radius case of the all-cap image theorem: the zero-noise field
copy contracts by L^-1, leaving a fixed noise margin c a_j. The actual
original enlarged cut must satisfy lambda_noise g_j R_j<c_noise a_j.
The weighted reference tower, actual C1,alpha slot, own mothers and
current bounds remain included. The target radius is not a statement
about the yet-unknown numerical coupling x_(j+1).

The fixed core can be evaluated on this target and uses the same full
physical noise law. A rooted neutral allocation or the explicitly
declared unmarked symmetry completion must already have been supplied.
Any defects/common-factor terms omitted from that identity must be
included as additional forcing before applying the present note.

(C) The actual beta extractor is the same bounded physical affine
functional on this auxiliary target. Its norm is C a_j^-2. The core
and actual physical affine conventions agree there. Changing an
off-graph continuation alone is not a proof of this agreement.

(D) The prescribed-history core has the estimate

 beta_C,j+1=d_(j+1)+e_C,j+1,
 |e_C,j+1|<=C/x_j+C exp(-c R_j^2),                              (3)

with constants uniform in the admitted frozen history. The numbers
d_(j+1) are the complete native Gaussian increments for the SAME
geometric action, precision and beta convention. Suppose further

 |sum_(l=i+1)^k d_l-c_G(k-i)|<=C_G,  c_G>0,
 |d_l|<=B_G.                                                  (4)

The definition of d and proof of (4) are separate obligations. (4)
is a whole-stretch estimate; an O(1) error per elementary step is
insufficient to infer it with the same C_G.

2. ESTIMATING THE NEXT BETA BEFORE KNOWING THE NEXT COUPLING

Write D_j=D_E,j+M_j. On the auxiliary target from (B), let

 h_j=A_(j+1) Log Q_C,j exp(Delta_j D_j).

The allocation operator A is identity under exact native rooted
registration, or the explicitly declared norm-contracting Reynolds
operator from the companion bootstrap. In the latter case use its
invariant unmarked sector, stabilized domains and physical affine
matching. It preserves the physical beta only under those hypotheses.
It is outside the logarithm; all estimates below include it.

The current input bound (2) and the value compiler give

 p_j<=C a_j^2(A+R_*)x_j^-s.                                   (5)

Choose the weak floor so this is below the protected connected-cluster
reserve. The quantum value bound and the exact normalized quadratic
remainder, including full denominators, give

 ||A_(j+1) Q_C,j Delta_j D_j||_value
       <=C g_j^2(A+R_*)x_j^-s,
 ||h_j-A_(j+1) Q_C,j Delta_j D_j||_value<=C p_j^2.              (6)

Apply (C), on the auxiliary radius a_j. Then

 |delta_beta_(j+1)|
 <=C (g_j^2/a_j^2)(A+R_*)x_j^-s
          +C a_j^2(A+R_*)^2 x_j^-2s
 <=C x_j^-s.                                                  (7)

Every input to (5)--(7) belongs to the already constructed prefix.
In particular, a_(j+1) has not been substituted, and neither (1) nor
the comparison estimate is assumed at date j+1. This is the causal
point missing from a direct use of a future-radius operator bound.

Together with (3), (7) yields

 beta_(j+1)=d_(j+1)+e_(j+1),
 |e_(j+1)|<=epsilon(Y),                                       (8)

where epsilon(Y) can be chosen as

 sup_(x>=Y) [C/x+C exp(-c R(x)^2)+C x^-s].

Uniformly admissible schedules for which the cut term tends to zero
give epsilon(Y)->0. If no such schedule has been proved, retain that
term as an input; its smallness is not a consequence of parity alone.

3. STRICT IMPROVEMENT OF THE PREFIX BOUNDS

Choose constants with

 C0>=C_G,  0<lambda<c_G-epsilon(Y),
 B>B_G+epsilon(Y),  Y>=2C0.                                   (9)

Assume the actual recursion is x_(j+1)=x_j-beta_(j+1). At date zero,
(1) is vacuous apart from x_0>=Y and (2) has D_E,0=0. Suppose the
induction has reached date j with all inputs weak and all earlier
steps obeying (8). Apply Section 2. The new increment obeys

 |x_(j+1)-x_j|<=B_G+epsilon(Y)<B.                              (10)

For EVERY earlier i<=j, the Gaussian stretch estimate gives

 x_i-x_(j+1)
 =sum_(l=i+1)^(j+1) [d_l+e_l]
 >=[c_G-epsilon(Y)](j+1-i)-C_G
 >=lambda(j+1-i)-C0.                                         (11)

Thus the numerical increment and stretch conditions improve strictly.
If x_(j+1)>=Y, the longer prefix satisfies (1), and the existing
comparison theorem may now be applied to this longer finite horizon.
If x_(j+1)<Y, the prefix stops at its first weak-floor exit; (10)--(11)
remain valid for this last output because only its input was required
to be weak. No clipping or replacement step has been inserted.

This proves that the additional stretch/bounded-increment assumptions
cannot be the first failure on an otherwise admitted weak trajectory,
provided premises (A)--(D) and their physical identifications hold.
It does NOT prove that the weak floor is never reached.

The argument is valid with causal coefficient memory and signed steps.
It uses neither differentiation in old couplings nor continuity in
the bare coupling. The comparison can be re-run at each finite horizon;
uniform constants, not equality of distinct horizon norms, are used.

4. CONSEQUENCES CONDITIONAL ON A TUNED ENDPOINT

If a genuine admissible finite trajectory with x_N=X has independently
been constructed, (10)--(11) imply

 X+lambda(N-j)-C_G<=x_j<=X+B(N-j).                             (12)

Taking X>Y+C_G keeps all these inputs above Y. The original comparison
then supplies its summable rare coupling driver on that trajectory.

If the actual schedule also gives exp(-c R(x)^2)<=C x^-1, summing
(3),(7) and using (12) gives the refined bare endpoint estimate

 |x_0-X-c_G N|
 <=C_G+C log(1+N/(X-C_G))+C(X-C_G)^(1-s),                     (13)

with fixed constants and X-C_G>=Y. The harmonic term belongs to the
core O(g^2) error, while the regular/full-R difference is summable.
The cut condition displayed before (13) is explicit and optional;
without it retain the actual sum of cut errors.

5. UNDISCHARGED APPLICATION GATES

This bridge requires the exact common physical factor, admitted
auxiliary target, actual full R identification, rooted neutral range,
and common compiler reserve in (A)--(C). It additionally requires the
native Gaussian identity and uniform drift (D). The companion audits
must decide those facts from their proofs and primary formulas.

Even if those gates pass, exact endpoint shooting for the full native
RT recursion additionally needs finite causal continuity (or another
proved tuning mechanism). Rounding a partition or changing a hard cut
can change the decomposition-dependent extracted beta; smoothness of
the total finite lattice integral does not alone prove continuity of
that beta. This note makes no continuity claim and no continuum,
infinite-volume, reconstruction or interaction claim.
