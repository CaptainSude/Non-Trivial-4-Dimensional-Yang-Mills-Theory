NORMALIZED SCORE OF ONE ADMITTED NATIVE REFERENCE
19 October 2026. Turn 15 continuation; balaban_inputs.

Result

On one fixed admitted geometry, the primary reference expansion DOES
control the centered normalized score along an admitted holomorphic
parameter path. The large g^-2 background action cancels exactly. With
parameter radius r, the score standard deviation is at most C/r, with
C uniform in the prior fine refinement. For a Lipschitz observable of
the current output links its covariance with the score is at most
C(g/r) Lip(f). The deterministic derivative of the minimizing reference
field remains separate and is generally not small.

A protected interior coarse collar coordinate has such a path CONDITIONAL
ON the complete local-tower native minimum/field-class estimate specified
in Section4. The geometry and exact averaging identities do not present
a new obstruction, but that quantitative input is not primary-verified
in this pass. This is a fixed-branch result, not a theorem for
sharp branch selection, artificial tower seams, the modified run, or
the full current law. A remote exponential derivative is a further
weighted response assertion, isolated in Section6.

2. Actual conditional moments, with the retained window unchanged

Let s_e be w_e normalized on D_T. Remove C_e exactly. The denominator
is bounded below by integrating over a fixed ball B(0,t0) subset D_T,
using the upper quadratic and linear bounds in (1.2) and the lower
Haar bound. The numerator of E|B|^q is bounded above by the corresponding
whole-space Gaussian integral with exponent

              -lambda |B|^2/2 + C_ell |B| + C_R.

Consequently, for each fixed q,

                   E_(s_e) |B|^q <= C_q.                 (2.1)

Every constant depends on the current slice dimension, lambda,
Lambda_Q,C_ell,C_R and the fixed Haar/window margins; none depends on
the previous classical refinement depth. This is a statement about the
ACTUAL reference integral, not a tail borrowed from a different convex
completion. It follows directly from the primary reference bounds and
is simpler than the retained regular-fiber theorem of turn11.

3. Centered score estimate on an admitted analytic disk

Let z be a scalar complex parameter, |z|<r, with real z describing a
real admitted exterior family e(z). Suppose its chosen fine-field lift
stays in the original class used before (1.10) on the whole disk. Work
at |z|<=r/2; replace r by the distance to the disk boundary if necessary.
Keep the same G0,D_T,zeta,g and the same relative Haar coordinates.

Cauchy applied separately to the complete coefficients in (1.1) gives

 ||partial_z ell|| + ||partial_z Q|| <= C/r,
 sup_(D_T) |partial_z R| <= C/r.                           (3.1)

This differentiation is BEFORE normalization. The B-independent
partial_z log C_e cancels from every covariance. The remaining score is

 s_z(B) = -partial_z ell(B)
          -partial_z Q(B,B)/2-partial_z R(B).              (3.2)

Equations(2.1),(3.1), with q=4, imply

       Var_(s_e)(s_z) <= C/r^2,
       |Cov_(s_e)(F,s_z)| <= (C/r) sqrt(Var_(s_e) F).       (3.3)

The second formula is for real F, or the usual absolute L2 variance for
complex F. Bounded tests also satisfy C osc(F)/r. No lower bound for
the OLD history mass occurs. No exp[g^-2 A(U0)] factor survives.

There is a useful extra g for an observable of CURRENT output links.
Let f be Lipschitz on the compact link variables changed in Lambda,
with the Euclidean sum/product geodesic metric fixed once. For
F_z(B)=f(Phi_z(B)), fixed z and real B,

       |F_z(B)-F_z(0)| <= C g Lip_Lambda(f) |B|.

This follows along the group path exp(i t g B)V_Lambda and does not
differentiate a fine reconstruction. Combining it with (2.1),(3.2)
gives

       |Cov_(s_e)(F_z,partial_z log w_e)|
                      <= C (g/r) Lip_Lambda(f).           (3.4)

For a normalized trace of a fixed current-link Wilson loop, the
Lipschitz constant is bounded by its number of changed edges times a
representation constant. A fine loop or an already transported mark
needs its own Lipschitz bound; its edge count cannot be suppressed.

The full derivative is still

 partial_z K_e f = E_(s_e)[partial_z(f composed Phi_z)]
                    + Cov_(s_e)(F_z,partial_z log w_e).    (3.5)

The first term includes D_e V_Lambda, unchanged exterior links read by
f, and any declared gauge-frame response. Centering does NOT make that
deterministic response small. This prevents interpreting (3.4) as
near-identity transport of arbitrary observables.

5. Cutoffs, frames, and why there is no unrecorded boundary derivative

Within this fixed branch D_T and the relative tree slice are independent
of e; therefore differentiating the exact integral on this common domain
has no moving-boundary term. Baseline dependence is already in Phi and
the action. This is why the source's original B coordinates are retained.

The exterior gate chi_(k,Lambda) is NOT differentiated here. A real
coordinate path hitting its threshold requires either its jump term or
a different branch partition. Likewise a post-redraw class gate must be
inserted as part of the observable (and may destroy Lipschitz regularity),
or treated with its own surface/jump comparison. Randomizing a relative
gauge uses the V_Lambda-twisted action described in the joint-law note;
an e-dependent change of slice coordinates would require its actual
Jacobian and boundary terms. The present calculation chooses none.

6. Remote decay: exact missing weighted derivative, not a normalizer gap

To append exp[-mu d(c,Lambda)] to (3.3),(3.4), it is sufficient to prove
on the SAME lifted disk

 ||partial_c ell||+||partial_c Q||+
       sup_(D_T)|partial_c R|
       <= (C/r_c) exp[-mu d_source(c,Lambda)].             (6.1)

The source distance and the complete gauge/data footprints must be
retained. A bound in Euclidean distance cannot be substituted across
different native tiers without a separate comparison.

The primary (1.6) and (1.16)--(1.17) exhibit exponentially localized
minimum responses and center-action differences. They make (6.1)
plausible via the native differentiated minimum kernels. They do not
literally state (6.1) for a free retained coarse-coordinate derivative:
one must compose the differentiated reference action with the local
lift(4.1), include the response of H_(1,k), the cutoff-weighted action,
the reference minimum, and the fixed gauge conventions. Bounding only
D_e U0 or only the log normalizer I(U0) omits some of those terms.

If the full native response theorem supplies the standard positive
connected-kernel majorant for these derivatives, convolution pays a
fixed fraction of its exponential rate and proves (6.1). This pass
does not certify that full derivative-majorant attachment from the
inspected primary pages. Consequently the nonremote fixed-branch
estimate(3.4) on an admitted fine-field disk is the proved useful
consumer. Its protected coarse-coordinate version uses H_min, whose
primary attachment remains explicit; a universal remote score bound
or all-history selector estimate is not asserted.
