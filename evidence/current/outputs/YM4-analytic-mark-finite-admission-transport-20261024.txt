RESULT

The existing protected-insertion construction gives an analytic,
linear, normalized one-column estimate for a bounded holomorphic
mark on a fixed complete read, provided its ENTIRE native localized
noisy image lies in the mark's own domain. A fixed source radius
need not equal the larger source-zero action radius. All source-zero
operator bounds, cuts, couplings, and Gaussian normalizations stay
those of the original action.

There is an exponential protected-read price for an unweighted
arbitrary seed. The current native absolute expansion does NOT turn
this into a polynomial merely because there is one source. On a
complete-carrier norm that price is paid by the input spatial reserve;
native coarsening restores a fixed weaker output exponent. Thus a
finite sequence need not incur exp(C L^(4t)) if EVERY current part
is actually localized and reblocked. The original source-position
census L^(4t) is a multiplicative factor, not an exponentiated body
size. Frozen old-date baselines obey a different ledger.

The theorem below is conditional only on the explicitly identified
source-specific image inclusions and the already registered native
source-zero/localization modules. It proves what follows from those
inclusions; it does not invent them for generated coefficients. The
current first cavity entry has a concrete matching program in the
companion source-domain note. All later admission remains separately
checkable. No assertion about arbitrary mixed histories is made.

3. WHY ONE MARK DOES NOT ERASE THE SEED EXPONENTIAL

The exclusion expansion alone has an absolute majorant containing
arbitrary compatible attachments at different seed cells. Even if
there is just one allowed tiny attachment of weight t>0 per cell,
the exact positive sum is (1+t)^h for h seed cells. Source-independent
cluster convergence therefore does not imply a polynomial-in-h bound
for this absolute sum.

The same limitation appears in a finite abstract hard-core gas with
h independent singleton activities -s, 0<s<1 small, and one marked
activity lambda M whose support covers all h cells. Its partition
function is (1-s)^h+lambda M, so its normalized first mark is
M(1-s)^(-h). This is a counterexample to a conclusion from generic
small-activity and distinguished-polymer algebra alone. It is NOT
asserted to be a Wilson bounded-source representation: exact positive
real-kernel structure would impose further relations on H'_D.

Thus a sharper polynomial theorem would need an additional
source-specific normalized complex marginal/contour estimate or an
exact resummation inside the protected body. Merely differentiating
an action cluster expansion does not supply it. The already proved
real inequality |QF|<=||F|| is true but does not by itself bound the
native complex coefficient norms used in (5).

where m_j records the actual finite inverse-spare margins when needed.
The actual bounded running increment |x_(j+1)-x_j|<=D implies

 N_t<=N_0 exp[C t log x_0+C t log(2+t)]
                  <=N_0 exp[C'(log x_0)^2].              (12)

This retains the L^(4t) source census and any fixed polynomial
inverse-radius/margin losses. There is NO exp(C L^(4t)) term:
large current carriers are controlled at each step by their existing
complete-tree weight and the restored exponent (8). Reconstructing
an entire union of all old supports and paying it as a new unweighted
seed would be a different, uncontrolled estimate.

For the cavity packet,

 N_0<=C_seed |c_a f_p| beta^6
                      exp[-c beta epsilon0^2],
 beta epsilon0^2=c_W A0^2 (log x_0)^(2p0).               (13)

The fixed initial complete read and its initial exponential weight

Equation (12) is a numerical consumer, not evidence for the missing
intermediate image hypotheses. Even finite t growing as log x_0
requires uniform control of every generated current coefficient's
own-pair domain and of the complex localization maps. A source's
original fixed fine-link formula does not automatically remain the
