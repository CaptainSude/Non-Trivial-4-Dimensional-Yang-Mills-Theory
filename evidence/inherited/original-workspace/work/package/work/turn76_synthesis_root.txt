1. A FIXED ANALYTIC DOMAIN IS NOT REQUIRED FOR EVERY HOMOGENEOUS SOURCE

The preceding homogeneous native core construction can carry a source
on its running radius a_j=g_j ell_j^p, ell_j=1+|log g_j|. The unmarked
core and its conditional density scores still use their own fixed
larger domain. These are different assertions about different objects.
In particular this does not extend the unmarked running remainder D.

For one fixed q-block of the actual core-only conditionals, all cutoff
and conditional normalizers retained, the source estimate is

 ||(L^C_(j,q)-T_(j,q))r||_(a_out)
                <= C_q [sum_l g_l^2/a_j^2] ||r||_(a_j).

It holds for already admitted, complete homogeneous neutral-source
families with the actual Ward, frame, and source-root properties. The
same ordinary classical low-jet and whole high-remainder estimates
give contraction in the normalized neutral norm

                       t_j=||r_j||_(a_j)/a_j^2.

After q, the minimum period and the weak floor are fixed, its factor
is bounded by kappa+C delta_j+C exp(-cQ_out)<1, with
delta_j=O(ell_j^(-2p)). Source noise admission still requires
g_j T_j/a_j small. The finite-period Maxwell leakage is retained;
the classical map is not asserted to preserve beta exactly.

The fact that delta_j alone is not summable does not invalidate this
scheme. The new coupled sequence calculation first controls the source
amplitude. With a fixed-core neutral part c_j, a running neutral part
r_j, and the same physical reference coefficient alpha_j, assume the
actual native decomposition has normalized running forcing
eta_j<=C g_j^K, K>2. Starting from the unit coupling-free reference,
it then gives

 ||c_j|| <= C g_j^2 exp(C A_j),
 t_j     <= C g_j^K exp(C A_j),
 |alpha_j-1| <= C A_j exp(C A_j),

 A_N=sum_(j<N)[g_j^4+epsilon_j g_j^2
                         +(1+delta_j+epsilon_j)g_j^K].

Thus the running contribution to the marginal is delta_j g_j^K,
not delta_j. Bounded SIGNED steps of gamma_j=g_j^-2 suffice for the
geometric convolutions. With gamma_j>=G+d(N-j) and the actual backward
periods Q_j=L^(N-j)Q_end, the estimate is uniform in depth:

 A_N <= C[G^-1+G^(1-K/2)+G^-1 exp(-cQ_end)].

A raw unnormalized forcing O(g^P) becomes
O(g^(P-2)ell^(-2p)) after division by a^2. P>4 is a simple sufficient
condition; this lost power is not omitted. Scalar source terms remain
in their separate exact ledger.

This proves the sequence calculation, conditional on the actual source
typing and forcing. It removes the demand to extend every healed source
to a fixed ball. It does not show that all raw or boundary terms already
belong to the running homogeneous class.

3. THE FRESH SOURCE COMPARISON CAN BE MADE BEFORE FREE-CURRENT EXTENSION

A complete fresh insertion may be re-represented when the new expression
agrees at EVERY actual physical read, including retained noise and passive

then be recomputed. This cannot be used to change only a favorable
masked part of an old fixed coefficient.

At an actual native private integration the four unnormalized entries
are I_0, I_F, I_H, I_FH. They retain the original OLD insertions and all
their exterior dependence. The new normalized reference q_e multiplies
these entries; it does not replace F by a similar-looking function of
the new reference field. A later first/second-class test is applied
after that new draw.

This gives a better chronological formulation of the next comparison.
For the SAME freshly formed complete coefficient D, set

 D_ad(d)=D(Psi_ad(d)),

current extension is chosen. One may seek a boundary estimate on the
actual Delta rather than an ideal-descent theorem for arbitrary old

4. WHAT PHYSICAL NULLNESS DOES LOCALIZE, AND WHAT IT DOES NOT

On an admitted common birth fiber, the averaged Hessian formula gives
p-p_*=Sigma_p d_fiber s(p). For a complete physical-null source this
factors its difference through the constrained force. On an adaptive
stationary background, determining rows that factor through the birth
average annihilate birth-fiber tangents exactly. Only the nonfactoring
rows, and any unremoved gauge force, remain.

For a physical-current read, the source must first be composed as
N_phys(p)=N(p,J_W(p)); its derivative includes D_J N composed with
D J_W. For a genuinely independent J the residual
N(p,J)-N(p,J_W(p)) remains. It has no automatic boundary support.
A local retraction also leaves its comparison to the homogeneous
retraction; that first term cannot be declared zero.

Finally, endpoint stationarity is not automatically stationarity after
independently decoupling an inverse. If G(1)Q*=0, the exact remaining
term is G(s)Q*lambda=[G(s)-G(1)]Q*lambda. Its connection to an artificial
cut is not yet a connection to an actual raw owner. The actual native
layer-current identity, or a proved matched constrained localization,
must be retained. These distinctions delimit the next comparison
rather than remove it by physical nullity alone.

Even exact constraint annihilation does not alone give spatial
decoupling. With precision I_2 and one retained row Q=(1,1), the
constrained inverse is (1/2)[[1,-1],[-1,1]]: it annihilates Q* but
still connects the two sites. Every determining row's complete
footprint must therefore belong to the comparison graph. Changing
the row introduces its multiplier and datum derivative terms as well.
The appended native assessment verifies this distinction explicitly.

5. A TERMINAL FILTER GIVES A MORE PRECISE ORIGINAL-LAW TARGET

Suppose an actual half-local forward kernel K has conditionally
independent reflected halves and let nu=mu K for the ORIGINAL law mu.
For 0<=A<=1 and real |f|<=1 in its positive-half output algebra, put

 Z=nu(A Theta A)>0,
 nu_A=Z^-1 A Theta A nu,
 c=nu(Af)/nu(A),             G=A(f-c)/2.

Then G is bounded by1, its original pullback is centered, and

 C_mu(K_+G)=Z/4 [C_(nu_A)(f)+(nu_A f-c)^2]
                         >= Z C_(nu_A)(f)/4.

The two-half filtered mean is not silently identified with c.
This permits a filter on a terminal property, with earlier healed
histories still included. It need not require absence of every bad
event throughout the ultraviolet history.

An actual finite Wilson benchmark is available. On a fixed finite
SU2 graph at fixed positive couplings, the exact positive injective
transfer matrix gives a strictly positive centered slice correlation
for every bounded nonconstant gauge-invariant slice function and every
nonzero separation below the temporal period. The paired spectral
formula also proves strict decrease up to half the period. For N>=8,
both C(4)>0 and C(2)-C(4)>0 have positive minima over a fixed compact
set of positive Wilson couplings.

These are finite-graph benchmarks, including one for time dependence.
Their compactness proof gives no cutoff-uniform or weak-coupling lower
margin, and no assertion that a retained native error is smaller than
that margin. A TV comparison of the two probe reads would transfer the
correlation with error at most6delta, if it were proved.

Two actual native problems prevent using this immediately. A single
reference replacement crossing the reflection plane may create fresh
correlations between the halves. Conditioning on a newly sampled
boundary variable merely exposes an extra conditional covariance; it
does not make that variable part of the original field. Also, a global
no-current-raw filter reads up to the reflection plane. A strictly
positive-time original observable requires the filter and EVERY
backward determining, gauge and decision read to stay away from it.
The suitably located single-component native replacement attaches;
the complete global forward map with those properties does not yet.
