RESULT

For two admitted literal first-success backgrounds that agree on a
complete coarse buffer, the marginal of a bounded thin PHYSICAL source
has a quantitative endpoint comparison. No derivative of the bounded
Borel source is used. The two original product cuts and their exact
normalizers remain in the original laws. A common physical-source
rechart compares positive auxiliary local ratios; the difference from
the original cuts is a separately displayed rare tail.

For a fixed eligible physical read P, complete active/free boundary
reads I,B, and separation D from changed determining data, the result is

 TV(law_1(Phi_1|P),law_0(Phi_0|P))
 <= min{1, C min(1,lambda_D)+C sqrt(|B|) exp(-nu D)
                      +C(|I|+|B|) exp(-c r^2)},                 (1)

where, for S=K r with a sufficiently large fixed K,

 lambda_D = C P_I delta_D [S^2+g(S+S^3)+S/g+1],
 delta_D = C epsilon_cmp exp(-kappa D).                        (2)

P_I is an explicit finite polynomial price for the actual source/pivot
and action read, with constants depending on the native fixed L and
strict physical chart margins. One may bound lambda_D by
C P_I (S/g)delta_D when S>=1 and gS is below the fixed physical cap.
In the original first-step regime epsilon_cmp<=C g r this yields

 C P_I r^2 exp(-nu D)+C(|I|+|B|) exp(-c r^2).                  (3)

Use the full (2) if that comparison cap has not been registered.
There is no ambient-volume count in (1). The additive cut tail in (1)
is not claimed to decay with D. This is a physical SOURCE marginal,
not the full state marginal: remote fields may differ by order one.
The exact raw mass of either endpoint is not compared by this theorem.

1. EXACT ORIGINAL LAWS, SOURCE CLASS AND COMPLETE READS

Fix the finite first-bare torus, coupling g, block grid, original
private-pivot convention and independent free index set. At each
endpoint sigma=0,1 use the registered literal first-success density

 mu_sigma(dx dz)=Z_sigma^-1 exp[-H_sigma(x,z)]
                          1_(K_r^I x K_r^J) dx dz,
 T_sigma f=mu_sigma[f(Phi_sigma(x,z)|P)], H_sigma(0)=0.          (4)

H includes the actual fine Wilson action, nonlinear constraint/current
correction, averaged gauge, Haar/pivot and coarea terms. The original
zero-noise stationary/scaling scalar C_out,sigma compensates H(0)=0;
the original raw mass is C_out,sigma Z_sigma, with every earlier
record indicator retained. There is no inherited effective action
here. The first soft-gauge gap is the registered converted native gap,
not an identification of the hard-AX and averaged-gauge slices.

Both endpoints must satisfy the native first minimum/current regularity
and common-shell hypotheses, and the complete first weighted Hessian
and local-force hypotheses on the containing products used below.
These hold on the already registered strict first-bare near-flat
family. The theorem also applies to other native admitted endpoint
pairs once precisely these inputs are verified; a small curvature
number alone is not substituted for admission. No global interpolation
of physical backgrounds is assumed.

The fixed P is the source's COMPLETE physical fine-link read. Require
an unused private interface link outside P in each constraint row
whose old pivot belongs to P. Choose those new pivots once. Native
B109(0.11)--(0.12) reads the two endpoint blocks and its own interface;
different row interfaces are disjoint. Each candidate has nonzero
flat derivative L^(1-d) times the color identity for the PHYSICAL
coarse average. The actual nonlinear implicit inversion on the
strict chart therefore makes every source link free. This is the
constructor in source_compatible_native_pivot_feasibility_20261024,
Sections1--3, already used by the audited first thin-source projection.

I is a set of ORIGINAL independent free indices. Include every old-free
variable in the reconstruction of the physical source arguments
(including any formerly solved source pivot), every old-free replacement
pivot used by the source-freeing chart, every changed-row two-block free
read, and all affected reconstruction/Jacobian stencils. The formerly
solved physical source pivot belongs to P and the complete physical
read, not literally to I. Boundary pivots whose rows meet I remain
SOLVED variables in the original coordinates. Let B subset J be the complete finite
old-free read outside I of the surviving local action difference,
source maps and rechart. Terms not meeting I cancel in H(x,z)-H(0,z).
Consequently the conditional constructions below depend on z only
through z_B, even though the original exterior marginal is global.
No independently held physical argument of f is allowed outside this
active/recharted read. Enlargement of I is required if one occurs.

All coarse determining, current, endpoint-contour, return, gauge,
constraint and both-endpoint-block reads are included in a finite
packet T containing I and B. W is a common complete coarse buffer
with the native comparison collar, on which V_0=V_1 in a common fixed
coarse frame. D is the distance of T to the changed determining shell,
after removing all fixed native read/collar widths. The actual fixed-L
conversion between fine-free and coarse distances is included.

A common fixed coarse gauge and its block lift may be applied to both
endpoints to choose the same protected local chart; the original balls
are invariant under this simultaneous orthogonal adjoint change. For
noninvariant f the corresponding fixed pullback is applied to f too.
Equivalently (1) compares the physical marginals in one fixed aligned
frame. No arbitrary fine gauge is applied to either original cut.

The class is nonempty: the literal four physical links of a fine
plaquette satisfy the unused-interface test for the native block size;
a bounded Borel function of those links is allowed. A remote small
change of coarse data with the complete local determining packet held
fixed gives two actual admitted endpoints. A thick hybrid whose read
contains complete constrained rows is not admitted by this constructor.

2. MATCH THE ORIGINAL AVERAGED-AXIAL REPRESENTATIVES

averaged-axial conditions U_sigma(y,x)=1. Endpoint covariance gives

 (U_1^u)(y,x)=u(x)^-1,   U_0(y,x)=1.

The finite endpoint contours and their analytic group mean are

             |U_1-U_0|+|J_1-J_0| <= C delta_D.                 (5)

This is an estimate, not a gauge substitution in the measures. It
resolves the difference between closeness modulo a relative gauge and

The primary anchors are B119 printed248(1.12), printed249(1.14)--(1.16),
and B109 printed267--270. The underlying common-shell comparison and

All first-bare coefficient maps are finite-read at fixed L. The

Thus (5) controls both complete local action coefficients and the

3. COMMON PHYSICAL SOURCE VARIABLES AND BOTH DOMAIN INCLUSIONS

At fixed common z_B define the actual invertible local charts
Psi_sigma,z from old active noise x to t=(y,v). Here y is the physical
source-link logarithm in ONE fixed unitary reference frame, divided
by g if desired; v denotes the remaining independent coordinates
selected by the private-pivot construction. Thus the source is exactly
the SAME f(y) at both endpoints. No source value is analytically
continued or differentiated. The actual coarse row targets touched
by I coincide, because W contains their complete determining data.

Let X_sigma,z be the inverse MAP only. Complete local implicit bounds,
(5), and the native nonzero private-pivot derivative give BOTH

 ||X_1,z Psi_0,z(x)-x||_infty <= C_P delta_D/g,
 ||X_0,z Psi_1,z(x)-x||_infty <= C_P delta_D/g.                 (6)

These hold on the required containing local products with strict
margins, uniformly for |z_B|<=c_B r. The same proof bounds their
Jacobian differences in the physical chart. One can derive (6) by the
finite local implicit mean-value formula, allowing off-graph local
coefficients after complete linear cancellation; it does not require
a global straight path of physical minima. All current and pivot
coefficients are included in C_P. The factor 1/g is the physical-to-
normalized-noise conversion.

Choose S=K r, K>=8, with

 gS <= epsilon_cap,   C_P delta_D/g <= S/16,                  (7)

and enough spare physical chart margin for both maps. Fix the SAME
pair-specific integration set

 D_star,z=Psi_0,z(K_(S/2)^I),   K_sigma,z=X_sigma,z(D_star,z).

The forward inclusion from (6) yields K_1,z subset K_(3S/4)^I.
For the reverse inclusion apply the SECOND transition in (6) to an
arbitrary x in K_(S/4)^I: Psi_0,z^-1 Psi_1,z(x) lies in K_(S/2)^I.
Consequently

 K_r^I subset K_(S/4)^I subset K_sigma,z subset K_(3S/4)^I
                                      subset K_S^I.           (8)

For sigma=0 the middle domain is exactly K_(S/2). This proof uses
both directions; a bound on only one image would not imply (8).
The original domains remain K_r^I, or equivalently their exact moved
images Psi_sigma,z(K_r^I). D_star is auxiliary and is NOT substituted
for the original successful event.

Condition (7) is local. In particular an auxiliary endpoint with a
larger global comparison cap can still use fixed K if its actual
inner difference delta_D/(g r) is bounded. It is not necessary to pay
the global cap instead of its exponentially small local value.

4. EXACT NORMALIZED AUXILIARY RATIOS AND ORIGINAL OUTER MASS

Set h_sigma,z(x)=H_sigma(x,z)-H_sigma(0,z) and
Z_I,sigma(z)=int_(K_r^I) exp[-h_sigma,z(x)] dx. Exact disintegration is

 pi_sigma(dz)= Z_sigma^-1 exp[-H_sigma(0,z)] Z_I,sigma(z)
                                                 1_(K_r^J) dz. (9)

Every original exterior scalar/record factor multiplying (9) is kept
at its original place. In particular no auxiliary local partition
function replaces Z_I,sigma in pi_sigma.

Let G={max_(b in B)|z_b|<=c_B r}, choosing the fixed c_B small enough.
The proved first-bare mean Cg and subGaussian coordinate tails give
pi_sigma(G^c)<=C|B|exp(-c r^2). For z in G the complete mixed Hessian
row and boundary-score estimate give mean at most Cg+C_B|z_B|<=r/4
under the conditional containing product K_S. Its strong-convexity
tails therefore imply

 nu_sigma,S,z(K_S^I minus K_r^I)<=epsilon_I,
 epsilon_I=C|I|exp(-c r^2).                                   (10)

Assume epsilon_I<=1/4; this is a finite source/read weak-floor condition,
not a bound involving the ambient torus. The mixed-score argument and
its exact local-fiber scope were audited in the thin-source projection
Section7. The containing continuation does not enlarge the original
law. The action/current primitive remains on gS<=epsilon_cap.

Define the positive auxiliary ratio

 A_sigma,z f = [int_Dstar f(y) w_sigma,z(t)dt]
                          /[int_Dstar w_sigma,z(t)dt],
 w_sigma,z(t)=exp[-h_sigma,z(X_sigma,z(t))] |det D_t X_sigma,z|. (11)

The old complete density under change of variables is already (11).
There is NO extra new-coarea factor: all old Haar/coarea terms are in
h and the exact coordinate Jacobian appears once. Equivalently one
may derive the new coarea directly from the physical constrained
measure, obtaining exactly the same expression with its common
scaling conventions.

By (8),(10), |T_sigma,z f-A_sigma,z f|<=osc(f) epsilon_I/(1-epsilon_I).
Choose a fixed linear evaluation c(f) preserving constants and put
J_sigma(z_B)=1_G A_sigma,z f+1_(G^c)c(f). Then

 T_sigma f=pi_sigma J_sigma+E_sigma f,
 |E_sigma f|<=C osc(f)(|I|+|B|)exp(-c r^2).                   (12)

The function J_sigma is a bounded B-cylinder of range contained in the
range of f. This pair-specific projection need not equal an earlier
flat-based analytic projection; each is compared to its original T
with its own exact error. Its flat error need not vanish. If desired,
(11) is holomorphic in a sufficiently small endpoint parameter
neighborhood with Dstar fixed there, by the already proved shrinking-
tube argument; such analyticity is not used in the real comparison.

5. A DENSITY RATIO THAT NEVER DIFFERENTIATES f

On the complete local read and |x|,|z|<=S, the endpoint action producer
(18) gives

 sup_x |h_1,z(x)-h_0,z(x)|
       <=C P_I [S^2+g(S+S^3)] delta_D.                       (13)

The first-bare force satisfies |grad h_sigma,z|_infty<=C_P
[S+g(1+S^2)]<=C_P S for S>=1 and small gS. The map displacement (6)
then contributes at most C P_I S delta_D/g. The exact local Jacobian
ratio contributes C P_I delta_D; common fixed g-scaling factors
cancel in this ratio. All determinants are on the common real
orientation-preserving branch, with uniform strict inverse margins.
Thus on the SAME Dstar

 |log w_1,z(t)-log w_0,z(t)|<=lambda_D                         (14)

with (2). A pure t-independent offset may instead be subtracted before
(14); it cancels only in the normalized ratio and stays in the raw
ledger (9). From (14), the normalized density ratio is between
exp(-2lambda_D) and exp(2lambda_D), whence

 |A_1,z f-A_0,z f|<=C osc(f) min{1,lambda_D}.                  (15)

All constants depend on the read and chart, never on derivatives,
continuity or an analytic extension of f. The use of S=K r improves
the conservative containing-radius epsilon_cap/g price to (3) in the
registered original cap regime. For small D when (7) is unavailable,
use the trivial physical TV bound one; no small comparison is claimed.

6. ORIGINAL EXTERIOR MARGINALS, FULL SOURCE TV AND CONTACTS

The exact difference of the projected means is

 pi_1 J_1-pi_0 J_0 = pi_1(J_1-J_0)+(mu_1-mu_0)J_0(z_B).       (16)

The first term is bounded by (15). The second is a fixed bounded NOISE
cylinder under the two complete original product laws. Apply
first_bare_endpoint_action_comparison_20261024 (16):

 |(mu_1-mu_0)J_0|<=C osc(f) sqrt(|B|)exp(-nu D).               (17)

That producer interpolates the COMPLETE endpoint actions on the SAME
K_r. Their weighted accretivity and primitive gaps survive convex
action interpolation. Its radius-independent first-bare mean and
fourth moments give L2 force-difference decay; conditional projected
score and full-law Poincare then prove (17). It does not interpolate
physical backgrounds. The outside-W coefficient cap is order one,
and its contribution is paid by the spatial convolution. The exact
normalization derivative is retained. If only its weaker pointwise
word version is registered, replace (17) by
C[r^2+g(r+r^3)]|B|exp(-nu D); the rest of this proof is unchanged.

Combining (12),(15)--(17) proves (1) for every bounded Borel f on the
SAME fixed P. Since the construction and constants depend on P, not
on f, the statement is exactly total variation of the aligned
physical-source marginals. No assertion about remote/full-state TV
follows. In particular the cutoff error in (1) remains additive even
as D tends to infinity.

For two sources the union of their complete reads must pass the SAME
unused-pivot test. Apply (1) to f, k and their raw product fk, keeping
the original source amplitudes. With epsilon equal to the right side
of (1),

 |Cov_1(f,k)-Cov_0(f,k)|
 <=epsilon[osc(fk)+||f||_infty osc(k)+||k||_infty osc(f)].      (18)

This includes the contact subtraction exactly. It introduces no
product of separate event probabilities. At each endpoint the raw
source column is C_out,sigma Z_sigma T_sigma f. Comparing raw columns
also contains the term (C_out,1 Z_1-C_out,0 Z_0)T_0 f. No small bound
on that mass difference is supplied or implied by (1).

7. AUXILIARY ENDPOINTS AND THE REMAINING COMPLETION GATE

The proof still compares an original endpoint to a same-form auxiliary
first-bare endpoint if the latter has the actual first constraint map,
physical minimum/current, strict primitive chart, complete soft-gauge
gap, containing-force/mean and native same-data comparison hypotheses
used above. Its product radius can be the same r for this comparison.
The original endpoint's measure and raw mass remain exactly original;
the second mass is auxiliary. No original P0/P1/Q1 admission is claimed
for the auxiliary endpoint from these analytic/convexity properties.

raw-link cap. In a different proposed completion the explicit
Section1 premises must be proved anew; the deterministic cutoff

This finite result closes the bounded-Borel physical pullback interface
