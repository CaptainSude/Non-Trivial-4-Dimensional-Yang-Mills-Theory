INCOMPLETE YM4 PROOF MANUSCRIPT

Read YM4-incomplete-proof.pdf. The main existence theorem is not proved.
The paper distinguishes exact finite identities, internally scoped results,
imported modules, conditional implications, and open completion gates.
The evidence corpus contains the detailed producers and audits.

Editable source: main.tex includes manuscript_core.tex.
The bibliography is included in the source; no external .bib is required.
With a standard LaTeX distribution, run from this directory twice:
  pdflatex -interaction=nonstopmode -halt-on-error -jobname=YM4-incomplete-proof main.tex

The generated PDF does not require LaTeX to read. Source paths in the
evidence appendix are relative to the package root (one directory above).
All standard theorem labels retain the epistemic scope stated in their
headings and proofs. No unpublished completion is imported.
