RESULT AND SCOPE

The curvature-square grading of the literal fine Wilson action does give a
useful source theorem on one actual homogeneous native regular primitive.
Its physical mixed conditional response has a leading term with TWO profile
differences and a fourth-order remainder, with the raw scalar coefficient
retained. This is the native-window version of the selected calculation in
TURN69, now attached using TURN74's native polynomial marks and TURN77's
literal fine-action reference. It has no inverse-fine-link cardinality loss.

This theorem applies to the complete reference insertion at that primitive,
not to the whole original source after arbitrary prior eliminations. The
full source also contains its earlier scalar, irrelevant and boundary jets.
Neither the h^4 grading nor differentiating an unmarked, retuned R-operation
removes those terms. The first unproved large-field interface can be stated
at the level of INTEGRATED two jets; it need not demand a pointwise analytic
reconstruction of every original link. Section 5 states that exact interface.

The new QED3 reference-response outline is assessed separately in
turn83_reference_response_history.txt. Its exact external-source Borel
identity and support-sensitive marked estimates are INPUTS. They are not
obtained there by differentiating unmarked bounds alone.

1. LITERAL ORIGINAL SOURCE AND THE STATIC CURVATURE CANCELLATION

Use h_p(U)=1-(1/2)Tr U(p) for SU(2), with the holomorphic trace convention
on complexified links and the real Wilson value on SU(2). At a finite
original regulator define

 S_f(U)=sum_p f_p h_p(U),
 Z(s,t)/Z(0,0)=E_original exp[s c0 S_f+t c0 S_h].             (1.1)

The canonical action choice is c0=beta0. The coupling-free source has c0=1.
A fixed physical calibration c0 is allowed, but changing c0 changes the
observable and is always stated. Equation (1.1) is the full original Wilson
normalizer. Equivalently the plaquette couplings are
 beta_p(s,t)=beta0-c0(s f_p+t h_p).
This exact identity is not yet a source bound for a renormalized branch.

On the fixed fine lattice the admitted native reference is

 R_i(f_i;U,J)=sum_p [A_p I_(i->0) f_i] h_p(U),             (1.2)

where A_p averages its four face vertices and I is the positive nested
multilinear interpolation. J is unused. With the same terminal profile,
R_i(I_(n->i)f_n;U)=R_0(I_(n->0)f_n;U) for EVERY fine field U. This is
an identity of functions on the same fine field, not an equality between
different minimum constructions. Differently masked sums have explicit
set-difference terms.

On the admitted born-i curvature domain, eta_i is the fine mesh in current
units and the plaquette logarithm is O(b eta_i^2). For the actual native
noisy-minus-static reference, the complete response catalogue gives

 |Delta h_p| <= C eta_i^4 [b g |x_H|+g^2 |x_H|^2].         (1.3)

Its localized version retains the source root and every response read.
There are O(eta_i^-4) plaquettes per current cell. Sum their nonnegative
interpolation weights and complete rooted majorants BEFORE replacing them
by their bounds. Thus (1.3) has a uniform current-root norm, rather than
an eta_i^-4 loss. This is precisely TURN77 gauge Section 5A, using the
native response imports in TURN26/29/74. It is not a bound on arbitrary
large-field original configurations.

2. A PHYSICAL NATIVE TWO-PROFILE RESPONSE THEOREM

Fix one of the actual homogeneous regular primitives at date j and a real
admitted physical minimizing background W. Include the COMPLETE action
whose constrained saddle defines that primitive, all crossing plaquettes,
the physical current, gauge/pivot terms and the actual noise window.
The body is the admitted fixed core. Running tags have their separately
proved interpolation corrections; this statement does not promote an
arbitrary running-domain body to the fixed-core class.

Freeze the window and all baseline parameters when varying the auxiliary
amplitude g. Let mu_T be the normalized centered correlated Gaussian with
that even retained window. The source is the actual fine reference (1.2):

 J_f(g,x;W)=R_f(U_noisy(g,x;W))-R_f(U_static(W)),
 L(g,s,t;W)=log int exp[V_g(x;W)+s J_f(g,x;W)+t J_h(g,x;W)] dmu_T,
 C_j(f,h;W)=partial_s partial_t L(g,0,0;W).              (2.1)

The native source-independent scalar prefactors remain in the density;
they cancel from this particular mixed derivative. The normalization by
the SAME integral is retained. In particular C_j includes its scalar
conditional covariance. It is not the quotient modulo constants.

Use the complete polynomial-mark/moment catalogues on the original native
noise and localization domains, as in TURN74 Sections 2--6. These prove
fixed fourth auxiliary-g derivatives with two distinguished source marks
and fixed complete-support margins. The noise coordinate is of current
scale. No Cauchy division by a shrinking complex-g radius is used.

Write the literal linear source jet as

 J_f=g L_f+O(g^2),
 L_f=sum_r x_r . l_f,r,
 l_f,r=sum_p f_p L_p,r.                                 (2.2)

The physical constrained stationarity of the COMPLETE action implies

                     sum_p L_p,r=0 for every r.          (2.3)

Equation (2.3) is imposed before any localization/carrier mask. It does
not hold for a masked partial action merely because the full action is
stationary. Nor is it asserted for the prescribed natural independent-J
extension away from the physical minimizing graph.

Choose a position x_r for the current noise block. Then exactly

                l_f,r=sum_p [f_p-f(x_r)] L_p,r.          (2.4)

Here f(x_r) and its Holder seminorm refer to the SAME actual continuous
interpolant that produces f_p by face averaging, with its fixed
interpolation constant retained. They are not unrelated continuum samples.

Let ell_j be the physical mesh of this primitive's current/source output
grid; changing to its adjacent input mesh costs the fixed block factor.
For 0<alpha,alpha'<=1, a fixed complete-support exponential reserve pays
the distance moments in (2.4). The rooted one-leg norm therefore gains
ell_j^alpha [f]_alpha, respectively ell_j^alpha' [h]_alpha'.

The actual parity is (g,x)->(-g,-x), with the same frozen cuts and
normalizers. Since V_0=0, J_f(0)=J_h(0)=0, and the linear jets are odd,
the exact expansion is

 C_j(f,h;W)=g_j^2 C2_j(f,h;W)+g_j^4 Rem_j(g_j;f,h;W),
 C2_j=Cov_mu_T(L_f,L_h).                                (2.5)

C2_j is the TRUNCATED CORRELATED Gaussian covariance. It is not replaced
by a product-ball constant or by the uncut covariance. If that replacement
is wanted, the native occupied-cutoff expansion pays its separate
exp(-c T_j^2) defect with both polynomial marks. No such replacement is
needed in (2.5). The remainder contains every higher source Taylor term,
every base interaction and both normalization derivatives. Taylor's
integral remainder and the retained fourth-order marked bound give
 ||Rem_j||_root <= C ||f||_infinity ||h||_infinity.

For disjoint actual interpolant supports at physical distance d>0, the
same complete connected catalogue gives

 |C_j(f,h;W)| <= C min(N_f,j,N_h,j) exp(-c d/ell_j)
   [g_j^2 ell_j^(alpha+alpha') [f]_alpha [h]_alpha'
                  +g_j^4 ||f||_infinity ||h||_infinity].  (2.6)

Here N_f,j counts current cells in the source's actual interpolation/read
collar. The constants depend on the fixed native margins and block factor,
not the original fine depth, total volume or j. They are the existing
marked-catalogue constants, not new numerical universal constants.

Proof of separation after recentering: a nonzero f_p-f(x_r) puts p OR r
in the support of f; similarly a nonzero h_q-h(x_s) puts q OR s in the
support of h. The carrier contains the paths p--r, r--s and s--q when
these are used by the contraction. It therefore still contains a point
of each support. The support moment used for (2.4) and the separation
reserve are distinct fixed fractions of the original exponent.

For complex free-pair estimates one may use TURN74's explicitly declared
coherent reduced extension at THIS birth, which agrees on the physical
graph. This does not authorize replacing an old native germ by that
extension under future R operations. The physical statement (2.6) does
not require that replacement at all.

For the source c0 S_f, multiply (2.5)--(2.6) by c0^2. In particular the
canonical original action has beta0^2, not beta_j^2 or 1. This calibration
cannot disappear by calling the reference a current-scale action.

3. WHAT CAN AND CANNOT BE SUMMED

For bounded physical supports N_f,j<=C_f ell_j^-4. If g_j<=g_*, then
the envelopes in (2.6) are summable over geometric scales up to any fixed
terminal ell_*, uniformly in the number of finer scales. For eps<=d,

 sum_(ell_j<=eps) |envelope_j|
 <= C exp(-c' d/eps)
    [g_*^2 eps^(-4+alpha+alpha') [f]_alpha[h]_alpha'
                         +g_*^4 eps^-4 ||f||inf||h||inf]. (3.1)

This follows by grouping ell_j=eps L^-r and absorbing every polynomial
L^(r(4-alpha-alpha')) into half of exp(-c d L^r/eps).
It is an envelope sum for births of the REFERENCE source. It is not an
additive decomposition of the full original covariance: later inputs
contain all inherited source coefficients and their mixed scalar jets.
The terminal/coarse conditional means remain. For canonical c0=beta0,
even this bound carries beta0^2; choosing a fixed c0 is a stated different
normalization, not a consequence of (3.1).

4. WHY AN UNMARKED COUPLING DERIVATIVE DOES NOT BYPASS THE SOURCE

There are two exact, different operations.

(a) Freeze the native transformation, cuts, reference kernels and original
coordinate record, and insert (1.1). The derivatives are exactly the old
source and its product. This is TURN74's finite raw-jet chronology. Its
analytic continuation must still be established on the actual later
native domains.

(b) Re-run the source-free transformation with changed bare couplings.
Then minima, derived cuts, reference kernels and normalizers may change.
The global total mass remains the sourced partition function, but an
individual output density derivative includes transformation scores.

Already the literal basic-R replacement shows this distinction. Fix its
choice label and surviving variables e. Write its output as
 rho_s(e,y)=A_s(e) q_s(dy|e), where q_s is normalized, and A_s is the
integrated OLD density with the original source. In a common fixed output
coordinate, at zero source,

 partial_s log rho_s = E(F|e)+partial_s log q_s,
 partial_s partial_t log rho_s
       =Cov(F,H|e)+partial_s partial_t log q_(s,t).       (4.1)

For q_s=r_s/int r_s,
 partial_s log q=partial_s log r-E_q partial_s log r,
 partial_s partial_t log q=partial_s partial_t log r
   -E_q partial_s partial_t log r
   -Cov_q(partial_s log r,partial_t log r).              (4.2)

These signs include the reference normalizer. If the exterior coordinates
also move, their transport/Jacobian scores must be retained as well.
Integrating a score against its own q gives zero at first order; it cannot
be dropped while later factors read y. Hence an unmarked parameter bound
for rho_s alone is not the old-source conditional bound. Large-I (1.100)
has exactly the normalized replacement factor to which this test applies.

There is also a concrete scalar diagnostic. On the one-plaquette SU(2)
Wilson integral, the classical minimum has h(I)=0, whereas

 Z_beta = const int_0^2 e^(-beta u) sqrt(u(2-u)) du,
 E exp[s beta h]=Z_(beta(1-s))/Z_beta
                  -> (1-s)^(-3/2) as beta->infinity.     (4.3)

Scaling x=beta u and dominated convergence prove convergence of all fixed
moments. Thus Var(beta h)->3/2. This is an actual compact Wilson integral,
not a YM4 counterexample. It demonstrates that a perfect classical
curvature bound does not bound or remove the generated scalar response.
For the coupling-free source its variance is 3/(2 beta^2)+o(beta^-2),
consistent with (2.5) for a constant profile. Separated mixed estimates
must localize these scalar responses; they cannot omit them.

  A_X^00, A_X^10, A_X^01, A_X^11.                        (5.1)

 ||A_X^ab||_(complete rooted operator)

6. DOES THE NEW HS-SMOOTHED INITIAL SOURCE REMOVE THAT GATE?

No attachment currently proves that. For the action, beta0 h_p is already
finite-read, gauge invariant and entire. Around a flat configuration its
norm is O(1) on a c/sqrt(beta0) link ball, and its vacuum-subtracted Taylor
series already begins at curvature degree two. A proved initial polymer
family for P exp(sum s_p beta0 h_p) can be useful, but these properties
alone do not improve its subsequent original-record domain.

The correct smoothed package retains P(original products), not products
of P(single marks). The buffered OS identity changes the initial half-
algebra representative; it does not intertwine P with each native T/R
kernel. After a partial elimination its complete original link halo still
has to be carried through the actual continued history. TURN82's Hilbert
analytic germ has precisely quantified refinement costs under that
pullback. An initially uniform flat-current/polymer estimate must show a
new bound on the actual native prepared response to affect (5.2).

For a nonanalytic bounded original probe the initial HS continuation is
genuinely new. For the local action source it should not be described as
closing the large-field source problem merely by supplying analyticity
and curvature grading that the bare action already possesses.
